사용방법

서비스 안내

지원할 사람들의 조건과 이용 가능한 강좌, 검토할 개선 조치와 예산을 입력하면 현재 상태와 조치 시행 후의 배정 가능 인원을 비교할 수 있습니다. 시설 가맹·강좌 개설·예약·결제를 실제로 처리하는 기능은 아닙니다.

예시 입력값 불러오기

아래에서 하나를 선택하면 지역·인원·시간·강좌·정원·조치·비용·예산까지 전부 채워집니다. 불러온 뒤에는 조합 계산만 누르세요.

기존 작성 내용이 필요하면 불러오기 전에 JSON으로 내보내 주세요. 공개 자료의 강좌 기록은 현재 모집 여부와 다를 수 있습니다.

  1. 1. 지역·종목 선택
  2. 2. 지원할 집단 입력
  3. 3. 강좌·정원 확인
  4. 4. 조치·비용 입력
  5. 5. 검증·조합 계산
계산 전 꼭 확인해 주세요. 추가 수용 정원과 개선 조치 비용은 공공데이터에 없어 직접 입력해야 합니다. 확인한 값은 담당자확인, 시험할 값은 가정으로 표시합니다. 빈칸은 미확인이며, 실제로 추가 수용이 불가능하거나 비용이 없는 경우에는 0을 입력합니다.

예시 입력값 선택 지역과 불러오기 수요 집단 강좌·정원 조치·비용 예산·계산 방식 검증한 입력 예시 결과 해석 오류 해결 저장·이동

1. 지역과 종목을 선택하고 기초자료 불러오기

시도·시군구·종목을 선택한 뒤 강좌·시설 불러오기를 선택합니다. 직접 작성하려면 + 집단·+ 강좌·+ 조치로 항목을 추가할 수 있습니다.

  • 기존 강좌: 선택한 지역·종목의 최근 운영 기록이 있는 가맹 강좌를 최대 20개 추가합니다. 운영 기록은 현재 모집 여부나 잔여석을 보장하지 않습니다.
  • 후보 시설: 가맹 검토 시설을 최대 5곳 추가합니다. 시설마다 신설 예정 강좌와 ‘가맹 협의 + 강좌 신설’ 조치가 생성됩니다.
  • 등록 수요: 해당 지역·종목의 희망 등록을 요일·시간대별 집단으로 불러옵니다. 등록 건수가 인원 초기값에 사용되므로 실제 이용 인원과 시간을 확인해 수정합니다.
  • 예시 집단: 불러올 수요가 없고 작성 중인 집단도 없으면 가정으로 표시된 예시 집단이 입력됩니다. 실제 지역 수요로 해석하지 않습니다.

불러온 자료에는 정원·사업비·신설 강좌 시간표 등이 비어 있습니다. 자료 불러오기만으로 계산 준비가 끝나는 것은 아닙니다. 검토하지 않을 항목은 삭제하고 필요한 강좌와 조치만 남겨 주세요.

다시 불러오면 기존 내용에 항목을 추가합니다. 다른 지역의 계획을 새로 작성할 때는 기존 내용을 내보낸 뒤 새로 만들기를 사용합니다.

2. 수요 집단: 누구를 몇 명 지원할 것인지 입력

같은 종목·시간·이동 조건으로 이용할 사람들을 하나의 집단으로 입력합니다. 최대 10개 집단을 작성할 수 있습니다. 개인 이름 대신 ‘초등 수영 집단 A’ 같은 집단명을 사용합니다.

항목입력 방법
이름·인원·종목집단명, 실제 검토할 인원, 이용할 종목을 입력합니다. 희망 등록에서 불러온 ‘1명’ 등을 그대로 사용하기 전에 실제 수요와 일치하는지 확인합니다.
연령(만)집단의 최소·최대 연령을 입력합니다. 강좌와 집단 양쪽에 연령 범위가 있으면 집단 범위가 강좌의 대상 연령 안에 있어야 합니다. 연령을 비우면 연령 때문에 배정을 차단하지 않습니다.
주당 횟수출석 규칙이 ‘요일 선택’인 강좌에 필요한 수업 횟수입니다. 비워 두면 1회로 계산합니다. ‘전 요일 필수’ 강좌의 출석 횟수를 줄이는 항목은 아닙니다.
이동·준비 여유수업 시작 전과 종료 후 각각 필요한 시간을 분 단위로 입력합니다. 예를 들어 16:00~17:00 수업에 15분을 넣으면 15:45~17:15가 이용 가능 시간 안에 있어야 합니다.
이동 수단자력 이동·기관 차량·이동 지원 필요를 선택합니다. ‘이동 지원 필요’ 집단은 강좌별 이동 가능 여부를 ‘가능’으로 확인하거나 해당 집단·시설의 이동 지원 조치를 선택해야 합니다.
이용 가능 시간+ 시간 추가로 요일별 이용 가능 시간을 입력합니다. 월·수·금 16:00~18:00이면 3개 행을 작성합니다. 모든 행을 비우면 시간 제약이 없는 것으로 계산됩니다.
출처확인한 수요는 ‘담당자확인’, 검증용 수요는 ‘가정’ 등으로 구분합니다. 출처 표시만 바꾼다고 인원이나 시간의 사실 여부가 자동으로 확인되지는 않습니다.

3. 이용 가능한 강좌: 시간표와 추가 수용 정원 확인

현재 이용할 강좌와 개설을 검토할 강좌를 최대 30개까지 입력합니다. 종목·시간·연령·가맹·이동 조건을 모두 만족해야 집단과 연결됩니다.

항목입력 방법
정원(추가 수용)강좌 전체 정원이 아니라 이번 수요를 추가로 받을 수 있는 자리입니다. 빈칸은 미확인으로 배정에서 제외됩니다. 추가로 받을 자리가 없으면 0을 입력합니다.
정원 출처실제 잔여 수용 인원을 확인했으면 ‘담당자확인’, 검토용 숫자이면 ‘가정’으로 표시합니다. 가정으로 표시해도 빈 정원이 자동으로 채워지지는 않습니다.
출석 규칙‘전 요일 필수’는 모든 수업 시간이 맞아야 합니다. ‘요일 선택’은 집단의 주당 횟수만큼 맞으면 됩니다. ‘미확인’은 보수적으로 전 요일 필수로 계산합니다.
시간표+ 수업 시간 추가로 실제 수업 요일과 시작·종료 시각을 입력합니다. 시간표가 없으면 정원을 입력해도 연결할 수 없습니다.
대상 연령강좌에서 허용하는 최소·최대 연령을 입력합니다. 집단의 연령 범위와 비교합니다.
가맹 여부현재 상태를 가맹·비가맹·미확인으로 입력합니다. 가맹이 아니거나 미확인이면 해당 시설의 가맹 협의 조치가 선택되어야 이용 가능으로 계산합니다.
존재 여부이미 이용할 강좌는 ‘기존 강좌’, 아직 개설되지 않은 강좌는 ‘신설 필요’입니다. ‘신설 필요’는 연결된 강좌 신설 조치를 선택해야 사용할 수 있습니다.
월 수강료강좌의 월 수강료를 기록하는 참고 정보입니다. 이 화면의 예산 비교는 개선 조치 비용으로 계산하며, 월 수강료로 지원 자격이나 본인 부담액을 판정하지 않습니다.
집단별 이동 가능 여부각 집단이 이 시설에 갈 수 있는지 선택합니다. ‘불가’이면 해당 이동 지원 조치가 필요합니다. 미확인 상태의 자력 이동·기관 차량 집단은 이동 때문에 차단하지 않으므로 실제 이동 조건을 확인해 주세요.

신설 정원은 중복 입력하지 않습니다. 아래 예시에서는 신설 예정 강좌의 기본 정원을 0, ‘강좌 신설’ 조치의 정원을 8로 입력합니다. 강좌에 8, 신설 조치에도 8을 넣으면 합계 16석으로 계산됩니다.

4. 개선 조치: 무엇을 시행하고 얼마를 쓸 것인지 입력

최대 10개 조치를 입력합니다. 조치 비용은 시설·기관에 확인한 값이나 검토용 가정값을 사용합니다. 0원과 비용 미확인을 구분해 주세요.

종류연결할 대상계산에 반영되는 효과
가맹 협의시설선택한 시설의 강좌를 스포츠 강좌이용권 사용 가능 상태로 가정합니다. 협의 조치만으로 신설 예정 강좌가 개설되거나 정원이 늘지는 않습니다.
강좌 신설대상 강좌·신설 정원선택한 강좌를 개설된 상태로 계산하고 지정한 정원을 추가합니다. 가맹·시간·이동 조건도 충족해야 배정됩니다.
정원 추가대상 강좌·추가 정원기존 정원에 입력한 자리를 더합니다. 기존 2석에 6석을 추가하면 총 8석입니다.
이동 지원수요 집단·시설해당 집단이 선택한 시설로 이동 가능한 것으로 계산합니다. 시설 가맹이나 강좌 정원을 대신 충족하지는 않습니다.
  • 선행 조치: 먼저 함께 선택되어야 할 조치의 ID를 입력합니다. 가맹 협의가 필요한 강좌 신설이라면 신설 조치의 선행 조치에 가맹 협의 ID를 적습니다.
  • 조치 ID: 카드 제목 앞에 표시되는 값입니다. 이름 대신 실제 ID를 사용하며, 여러 개이면 쉼표로 구분합니다. 후보 불러오기로 생성된 ID는 예를 들어 aff1·open1입니다.
  • 동시 선택 불가 조치: 함께 시행할 수 없는 조치의 ID를 입력합니다. 해당 조치들이 함께 포함된 조합은 비교에서 제외됩니다.
  • 불필요한 항목 삭제: 사용하지 않을 조치는 ×로 삭제합니다. 강좌를 삭제하려면 먼저 해당 강좌를 참조하는 조치를 삭제하거나 연결을 변경합니다. 남은 선행·동시 선택 불가 ID도 확인합니다.

5. 예산과 계산 방식 선택 → 검증 → 조합 계산

예산은 개선 조치 비용의 합계에 적용합니다. 예산을 비우면 상한 없이, 0을 입력하면 비용이 0원인 조합만 최선 후보로 검토합니다. 사업에서 실제로 쓸 수 있는 범위를 입력해 주세요.

계산 방식확인할 결과정원 처리
정원·비용 시뮬레이션몇 명을 배정할 수 있는지입력한 정원 범위에서 배정합니다. 미확인 정원은 배정에서 제외됩니다.
정원 미적용 비교강좌와 연결될 수 있는 집단이 몇 개인지정원을 적용하지 않습니다. 기존 정원이 0이어도 다른 조건이 맞으면 연결 가능한 집단으로 계산할 수 있습니다. 결과를 사람 수나 잔여석으로 해석하지 않습니다.

검증으로 참조 오류와 미확인 항목을 확인합니다. 오류가 있으면 수정한 뒤 조합 계산을 선택합니다. 정원 미적용 비교에서도 비용 미확인 조합은 예산 내 최선 조합에서 제외됩니다.

검증한 입력 예시: 수영 8명, 예산 90만 원

아래는 실제 웹페이지에서 검증한 사용법 설명용 가정값입니다. 실제 지역 수요나 시설 견적이 아닙니다. 재현할 때는 집단 1개·기존 강좌 1개·신설 예정 강좌 1개·조치 2개로 구성합니다.

검증 → 조합 계산을 선택하면 현재 상태는 0명, 가맹 협의와 강좌 신설을 함께 선택한 최선 조합은 8명·800,000원입니다. 가맹 협의만으로는 강좌가 생기지 않고, 강좌 신설만 선택하면 선행 조건을 충족하지 못해 비교에서 제외됩니다.

예산을 700000원으로 낮추면 80만 원 조합은 예산을 초과하므로 최선 결과는 0명입니다. 수요 집단의 가능 요일을 화·목으로 바꾸면 월·수·금 수업과 충돌해 두 조치를 선택해도 0명입니다.

결과 화면 읽는 방법

표시해석 방법
현재 상태추가 조치 없이 기존 강좌·정원으로 계산한 결과입니다. 미확인 정원이나 맞지 않는 시간 때문에 0명일 수 있습니다.
예산 내 최선 조합예산과 선행·동시 선택 불가 조건을 지키면서 배정 인원(정원 미적용 비교는 연결 집단 수)이 가장 많은 조합입니다. 결과가 같으면 비용, 조치 수가 적은 순으로 선택합니다.
개별 효과 순 선택 결과현재 선택 상태에서 효과를 가장 크게 늘리는 조치를 하나씩 추가한 결과입니다. 앞의 예시처럼 단독 효과가 없는 선행 조치가 필요한 경우 전체 조합 비교와 결과가 달라질 수 있습니다.
조치별 단독 효과각 조치를 하나만 선택했을 때의 결과입니다. 필요한 선행 조치가 없으면 ‘불가’로 표시됩니다.
상위 조합결과와 비용, 예산 초과·비용 미확인 상태를 확인합니다. 전체 조합 중 상위 최대 12개를 표시합니다.
배정 조건 확인‘이 조합 선택’ 또는 ‘선택’으로 조합을 바꿔 집단별 배정과 종목·시간·이동·가맹·정원 등 연결을 막는 이유를 확인합니다. 연결 가능한 강좌가 있어도 정원이 0이면 배정 인원은 0명입니다.
가정값 사용가정으로 입력한 조건이 포함된 결과입니다. 실제 확인값으로 수정하면 결과가 달라질 수 있습니다.

선택한 조합을 확인한 뒤 선택 조합으로 협의 계획서를 선택합니다. 예산 초과나 비용 미확인인 조합도 검토를 위해 선택할 수 있으므로 계획서 사용 전 상태를 확인합니다. 기본 초안은 AI 없이 작성되며, 활성화된 경우 AI로 문장을 다듬을 수 있습니다.

계산은 인원을 여러 강좌로 나누어 배정할 수 있습니다. 결과는 입력 조건에서의 모델상 배정 인원이며 실제 수강 신청·가맹 승인·사업비 집행 결과가 아닙니다.

계산이 되지 않거나 결과가 0명일 때

상황확인할 내용
‘신설 정원이 없어…’ 오류‘강좌 신설’ 조치의 정원을 입력합니다. 강좌 쪽 정원만 입력해도 신설 조치 정원이 비어 있으면 정원·비용 모드의 검증을 통과하지 못합니다.
‘참조 조치/강좌/집단이 없습니다’삭제한 항목을 다른 조치가 참조하고 있는지 확인합니다. 대상 선택과 선행·동시 선택 불가 ID를 수정하거나 불필요한 조치를 삭제합니다.
비용 미확인검토할 조치의 비용을 입력합니다. 비용이 실제로 없다면 0, 아직 모르면 빈칸으로 구분합니다. 빈칸을 가정으로 표시하는 것만으로는 해결되지 않습니다.
정원을 입력했는데도 0명시간표, 집단의 이용 가능 시간과 이동·준비 여유, 출석 규칙, 연령·종목, 이동 가능 여부와 가맹 상태를 확인합니다. 신설 예정이면 신설 조치도 선택되어야 합니다.
신설 예정 강좌가 많아 오류가 반복됨불러온 후보마다 신설 조치가 생성됩니다. 계산하지 않을 후보의 조치를 삭제하고 비교에 필요한 항목을 남긴 뒤 다시 검증합니다.
현재 상태부터 전원이 배정됨기존 강좌에 입력한 추가 정원이 충분한지 확인합니다. 이미 전체 수요를 충족하면 개선 조치를 추가해도 인원이 늘지 않아 비용 0원의 현재 상태가 최선일 수 있습니다.
정원 미적용 비교에서 정원 0인데 연결됨정원 미적용 비교는 정원을 적용하지 않는 모드입니다. 실제 인원 비교가 필요하면 정원·비용 시뮬레이션을 선택합니다.

작성 내용 저장과 다른 기기로 이동

변경 내용은 현재 브라우저에 자동 저장됩니다. 다른 기기로 자동 동기화되지는 않습니다. JSON 내보내기로 파일을 저장한 뒤 다른 브라우저의 JSON 불러오기에서 선택하면 옮길 수 있습니다.

새로 만들기와 JSON 불러오기는 현재 시나리오를 바꾸므로 필요한 내용은 먼저 내보냅니다. 저장 위치와 별개로 검증·계산·문서 생성 요청 시에는 입력 내용이 서버로 전송되어 처리됩니다.
