{{ heading('overview') }}

스포츠브릿지는 스포츠 강좌이용권 대상자와 지역 주민의 강좌·시설 검색을 지원하고, 지자체·공단·복지기관 담당자에게 지역별 공급 검토 자료를 제공합니다.

  • 이용자용: 조건에 맞는 강좌와 공공 운동 공간을 검색하고, 희망 강좌와 시설 이용 의견을 등록합니다.
  • 담당자용: 지역별 현황과 가맹 검토 시설을 확인하고, 시설 가맹·강좌 개설·정원 추가·이동 지원 방안을 비교합니다.

상단 메뉴에서 화면을 선택합니다. 모바일에서는 하단 메뉴와 더보기를 이용합니다. 주요 기능 옆의 ?를 선택하면 해당 기능의 설명이 표시됩니다.

{{ heading('problem') }}

스포츠 강좌이용권을 지원받아도 거주 지역에 가맹시설이 없거나 이용 가능한 종목·시간대가 맞지 않으면 실제 참여가 어렵습니다. 국회예산정책처가 인용한 2024년 만족도 조사에서는 지원기간 미소진 사유 중 ‘이용시설 부족’ 응답이 35.0%로 가장 높았습니다.

이용자는 조건에 맞는 강좌를 찾고, 담당자는 어느 지역·종목·시설부터 검토할지 판단할 수 있어야 합니다. 스포츠브릿지는 공개 자료와 익명으로 등록된 이용 의견을 함께 제공합니다.

출처: 국회예산정책처, 2026년도 예산안 위원회별 분석, p.184. 지원 대상 전체의 미이용 비율을 뜻하는 수치는 아닙니다.

{{ heading('user-mode', '/user', '조건에 맞는 강좌 찾기') }}

지역과 이용 유형, 희망 종목, 나이, 이용 가능한 요일·시간, 이동·준비 여유와 월 예산을 입력한 뒤 찾기를 선택합니다. 종목은 최대 3개이며 선택 순서가 우선순위입니다.

구분의미
조건 일치입력한 조건에서 불일치 사유나 추가 확인 항목이 없는 강좌입니다.
확인 필요출석 규칙·연령·수강료·시간표 등 확인되지 않은 항목이 있는 강좌입니다. 출석 규칙이 미확인이고 일부 요일만 맞는 경우도 포함될 수 있습니다.
조건 불일치종목·시간·연령·예산 등의 불일치 사유를 함께 표시합니다.

조건 변경 제안은 검색 결과가 증가하는 변경안입니다. 선택하면 변경된 조건으로 다시 검색합니다. 이용 가능 시간과 겹치는 개방학교 체육시설과 지역 내 가맹 검토 시설도 함께 표시될 수 있습니다.

☆ 저장으로 관심 강좌를 저장하고 지원금 계산에서 확인할 수 있습니다. 검색 조건 자체는 서버에 저장하지 않습니다. 희망 강좌 등록이나 이용 희망 등록을 선택한 경우에는 해당 의견이 저장됩니다.

‘조건 일치’는 현재 모집 중이거나 신청할 수 있다는 뜻이 아닙니다. 모집 여부·잔여석·실제 수강료는 시설에 확인하고, 신청·결제는 스포츠 강좌이용권 공식 사이트에서 진행해 주세요.
{{ heading('screen-user-region', '/user/region', '지역별 운동 시설·강좌') }}

시군구를 선택하면 집계기간에 강좌 기록이 있는 가맹시설·강좌 수와 종목·시간대·요일 분포, 이용자 의견을 확인할 수 있습니다. 지역 설명과 시설 목록을 함께 제공합니다.

‘집계기간 내 기록 있음’은 데이터의 강좌 기록을 기준으로 하며 현재 운영·모집 여부를 보장하지 않습니다.

{{ heading('screen-user-facilities', '/user/facilities', '스포츠 강좌이용권 사용 가능 시설') }}

지역을 선택한 뒤 종목·시설명으로 검색합니다. 저녁 강좌 있는 곳만, 집계기간 내 강좌 기록 있는 곳만 필터를 사용할 수 있습니다.

시설을 선택하면 강좌의 시간표·월 수강료·마지막 집계월 신청 인원을 확인할 수 있습니다. 마지막 이용 기록과 현재 모집 여부를 구분해 확인해 주세요.

{{ heading('screen-user-spaces', '/user/spaces') }}

지역별 개방학교 체육시설과 공공체육시설을 확인합니다. 자료에 있는 개방 시간·종목·편의시설과 시설별 안전·접근 정보를 표시합니다.

공공 운동 공간이 모두 무료이거나 스포츠 강좌이용권 가맹시설인 것은 아닙니다. 자료의 기준연도와 운영 여부, 요금·예약 방법을 시설에 확인해 주세요.

{{ heading('screen-user-voice', '/user/voice') }}

희망 강좌 등록에서는 종목·요일·시간대·대상 연령대·스포츠 강좌이용권 유형을 입력합니다. 이용 희망 등록에서는 목록에 표시된 시설을 선택합니다.

종목별·시간대별 등록 현황과 시설별 희망 등록 수를 확인할 수 있습니다. 시설 이용 희망은 담당자용 가맹 검토 점수에 최대 3점까지 반영됩니다.

이름·주소·정확한 나이는 저장하지 않습니다. 강좌 검색 결과에서 의견을 등록하면 검색에 입력한 지역·종목·요일·시간대·연령대·이용 유형·예산·이동 수단 등이 함께 저장될 수 있습니다. 등록 건수는 실제 이용 인원이나 가맹 승인 건수가 아닙니다.

{{ heading('screen-user-planner', '/user/planner', '스포츠 강좌이용권 지원금 계산') }}

계산할 강좌 검색에서 지역·종목·시설명 또는 강좌명을 입력하고 강좌 검색을 누릅니다. 결과의 수강료 적용을 선택하면 해당 수강료로 계산됩니다. 직접 수강료를 입력해도 됩니다.

지원 유형·월 지원 한도·지원 시작 월·전체 개월 수·계산 기준 월을 확인하고 지원금 계산을 선택합니다. 기준 월을 포함해 남은 기간을 계산하므로 이번 달에 이미 결제했다면 다음 달로 변경합니다. 월 예상 지원액은 수강료와 지원 한도 중 작은 금액이며, 한도를 초과한 금액은 본인부담금입니다. 0원은 무료로 계산하고 미입력·잘못된 값은 오류로 안내합니다. 실제 카드 잔액이나 결제 내역을 조회하지 않습니다.

저장한 강좌에서도 수강료 적용을 선택할 수 있습니다. 미확인 수강료는 적용할 수 없으며 시설에 확인 후 직접 입력합니다. 저장 강좌와 계산 입력값은 현재 브라우저에 보관되고, 재방문 시 계산 기준 월은 현재 월로 표시됩니다. 검색 결과의 현재 모집·요금·지원 유형별 결제 가능 여부는 시설에 확인해 주세요.

{{ heading('screen-user-agent', '/user/ask') }}

지역·종목·요일·시간 등을 문장으로 질문하면 관련 공공데이터를 조회해 답변합니다. 오른쪽 조회 과정과 답변 근거에서 사용한 자료를 확인할 수 있습니다.

이용자용 질문은 강좌·시설·지역 안내를 제공합니다. 담당자용 지원 방안 시뮬레이션은 실행하지 않으며, 개인별 지원 자격이나 등록 가능 여부를 확정하지 않습니다. AI 기능이 비활성화되어 있으면 질문 기능을 이용할 수 없습니다.

{{ heading('screen-user-help', '/user/help') }}

이용자용 주요 기능과 검색 결과 해석 방법을 간단히 확인하는 화면입니다. 자세한 화면 설명과 계산 기준은 현재 보고 있는 서비스 안내에서 확인할 수 있습니다.

{{ heading('screen-user-suggestions', '/user/suggestions') }}

서비스 개선 의견이나 기능 제안을 제목·내용으로 작성하고 제안 등록을 선택합니다. 로그인 없이 이용하며 작성자는 익명으로 표시됩니다. 모든 이용자가 글을 읽을 수 있으므로 개인정보는 입력하지 마세요.

제안은 최신 등록 순서로 20건씩 표시됩니다. 강좌·시설 이용 희망 통계나 가맹 검토 점수에 반영되는 의견은 희망 강좌·시설 등록에서 작성해 주세요.

{{ heading('screen-admin-suggestions', '/admin/suggestions') }}

최고 관리자 또는 승인된 관리자만 작성·열람할 수 있는 개발자 제안 게시판입니다. 작성자 이름·제목·내용을 입력합니다. 글에는 작성자 이름과 로그인한 계정 아이디가 함께 표시됩니다. 다른 관리자 화면의 인증을 비활성화해도 이 게시판은 로그인이 필요합니다.

두 게시판 모두 1시간에 5건까지 등록할 수 있습니다. 작성 후 직접 수정·삭제하는 기능은 없으며, 최고 관리자가 각 게시판에서 게시글을 삭제할 수 있습니다. 게시글 등록 시 이메일이 자동 발송되지는 않습니다.

{{ heading('screen-admin', '/admin') }}

지역 현황·가맹 검토·지원 방안·질문하기·데이터 관리로 이동할 수 있습니다. 최고 관리자(루트)로 로그인하면 관리자 가입 신청 목록도 표시됩니다.

관리자 가입과 승인

  1. 관리자 가입 신청에서 아이디·이메일·12자 이상의 비밀번호를 입력하고 인증 코드 받기를 선택합니다. 아이디는 3~32자이며 영문 소문자로 시작하고 소문자·숫자·밑줄을 사용할 수 있습니다.
  2. 이메일의 6자리 인증 코드를 10분 안에 입력해 확인합니다. 이메일 확인을 마치면 승인 대기 상태가 됩니다.
  3. 최고 관리자(루트)가 대시보드에서 승인하면 관리자 로그인으로 담당자용 화면을 이용할 수 있습니다.

최고 관리자(루트)는 신청을 승인하거나 반려·접근 해제할 수 있습니다. 인증이 꺼져 있어도 회원 승인·접근 해제에는 최고 관리자(루트) 계정 로그인이 필요합니다.

상세 입력 화면은 항상 표시됩니다. 사용방법의 예시 입력값 불러오기에서 공개 자료의 실제 강좌를 사용하는 정원 추가, 이동 지원, 정원·이동 결합, 두 집단 배정 중 하나를 고르면 모든 입력 항목이 채워집니다. 이후 조합 계산만 누르면 됩니다. 강좌·시설명·시간표·수강료는 공개 자료이고, 희망 인원·추가 정원·비용·이동 조건과 미확인 연령·출석 규칙은 가정값입니다. 기존 작성 내용이 있으면 교체 전에 확인합니다.

수요 집단, 기존·신설 예정 강좌, 개선 조치와 예산을 입력해 지원 방안을 계산합니다. 최대 수요 집단 10개·강좌 30개·조치 10개를 입력할 수 있습니다.

작성 중에는 해당 화면의 사용방법에서 항목별 설명을 확인할 수 있습니다. 검증한 8명 배정 예시와 오류 해결 안내도 제공합니다.

강좌·시설 불러오기

선택한 지역·종목의 집계기간 내 강좌 최대 20개와 가맹 검토 시설 최대 5곳을 추가합니다. 후보 시설마다 신설 예정 강좌와 가맹 협의 + 강좌 신설 조치가 생성됩니다. 신설 조치에는 가맹 협의가 선행 조건으로 지정됩니다.

등록된 희망 강좌도 종목·요일·시간대별 수요 집단으로 불러옵니다. 등록 건수가 인원 초기값에 사용되므로 실제 수요 인원을 확인해 수정해 주세요. 불러올 수요가 없으면 가정으로 표시된 예시 집단이 입력됩니다.

입력 시 확인할 사항

  • 수요 집단: 개인 이름 대신 집단명, 인원, 종목, 연령대, 이용 가능 시간과 이동 조건을 입력합니다. 이용 가능 시간을 비우면 시간 제약 없이 계산합니다.
  • 이용 가능한 강좌: 시간표·대상 연령·출석 규칙·추가 수용 정원·가맹 여부 등을 입력합니다. 시간표가 없으면 연결할 수 없고, 정원이 없으면 정원·비용 모드의 배정에서 제외됩니다.
  • 개선 조치: 가맹 협의, 강좌 신설, 정원 추가, 이동 지원을 선택합니다. 시설·강좌·집단 연결과 비용, 선행·동시 선택 불가 조치 ID를 확인합니다.
  • 정원·비용의 확인 상태: 확인한 값과 가정값을 구분합니다. 강좌 수강료와 개선 조치 비용은 서로 다른 항목입니다.

검증으로 입력 오류와 미확인 항목을 확인합니다. 신설 정원이 없는 등 오류로 표시되는 항목은 수정해야 비교 화면으로 이동할 수 있습니다. 정원이 없을 때 연결 가능성만 검토하려면 정원 미적용 비교를 선택합니다.

입력 내용은 현재 브라우저에 저장됩니다. JSON 내보내기·JSON 불러오기로 옮길 수 있습니다. 저장 위치와 별개로, 검증·계산·문서 생성을 요청하면 입력한 시나리오가 서버로 전송되어 처리됩니다.

  • 시간: 이동·준비 여유를 포함한 수업 시간이 같은 요일의 이용 가능 시간 안에 들어가야 합니다. 전 요일 필수·출석 규칙 미확인은 전체 수업을, 요일 선택은 필요한 주당 횟수를 비교합니다. 이용 가능 시간 미입력은 제약 없음, 강좌 시간표 미입력은 연결 불가로 처리합니다.
  • 이동·가맹: 이동 지원이 있거나 이동 가능이 확인되어야 합니다. 자력 이동·기관 차량 집단은 이동 여부 미입력 시 차단하지 않습니다. 이동 지원 필요 집단은 지원이 있어야 하며, 시설은 가맹 상태이거나 가맹 협의 조치가 선택되어야 합니다.
  • 신설·정원: 신설 예정 강좌는 강좌 신설 조치가 필요합니다. 정원·비용 모드는 확인되거나 가정으로 입력된 정원 범위에서 배정하고, 정원이 미확인인 강좌는 제외합니다.

정원·비용 시뮬레이션은 집단별 인원과 강좌 정원을 기준으로 최대 배정량을 계산합니다. 집단 인원은 여러 강좌로 나누어 배정될 수 있습니다. 정원 미적용 비교은 정원을 적용하지 않고 연결 가능한 집단 수를 비교합니다.

최대 10개 조치의 모든 조합을 평가합니다. 선행·배타 조건을 위반하는 조합은 제외하고, 예산 초과·비용 미확인 조합은 최선 조합에서 제외합니다. 여기의 예산은 개선 조치 비용이며 이용자의 월 수강료 예산과 다릅니다.

이용자와 보호자도 가입해야 하나요?

이용자용 검색·공공 운동 공간 조회·희망 등록은 관리자 가입 없이 사용할 수 있습니다. 담당자용 화면은 서버의 인증 설정에 따라 로그인이 필요할 수 있습니다.

인증 메일이 오지 않으면 어떻게 하나요?

입력한 이메일 주소와 스팸함을 확인해 주세요. 발송 오류가 계속되면 yojun313@postech.ac.kr로 문의해 주세요. 이메일 확인을 마쳐도 최고 관리자(루트)의 승인 전에는 관리자 계정으로 로그인할 수 없습니다.

강좌 정원과 조치 비용은 어디서 확인하나요?

현재 사용하는 공개 자료에는 추가 수용 정원이나 시설 가맹·강좌 개설 비용이 없습니다. 담당자가 시설·기관에 확인하거나 가정값으로 입력해야 합니다. 수강료와 조치 비용을 구분해 주세요.

시설 수가 적으면 부족한 지역인가요?

시설 수만으로 실제 수용 인원이나 이용자의 이동 조건을 알 수 없습니다. 순위는 지역 간 상대 비교이며, 현장 운영과 수요를 함께 확인해야 합니다.

희망 등록 건수를 그대로 수요 인원으로 사용할 수 있나요?

등록 건수는 실제 이용자 수를 확정한 값이 아닙니다. 지원 방안으로 불러온 집단의 인원·시간·연령을 확인하고 실제 수요에 맞게 수정해 주세요.

시나리오와 저장 강좌가 다른 기기에 표시되지 않아요.

시나리오·관심 강좌·지원금 계산 입력값은 현재 브라우저에 저장됩니다. 시나리오는 지원 방안 화면의 JSON 내보내기·불러오기로 옮길 수 있습니다. 브라우저 데이터를 삭제하면 저장 내용이 지워질 수 있습니다.

조치를 함께 시행한 결과가 개별 선택 결과와 다른 이유는 무엇인가요?

시설 가맹과 강좌 신설처럼 함께 시행해야 이용할 강좌가 생기는 경우가 있습니다. 조치를 하나씩 추가하는 방식은 이런 조합을 선택하지 못할 수 있어 전체 조합 비교와 차이가 납니다.

공공데이터는 실시간 정보인가요?

아닙니다. 원본별 기준일과 현재 적재된 버전을 기준으로 제공합니다. 모집 여부·잔여석·안전·개방 시간은 시설에 확인하고, 최신 파일을 업로드한 뒤에는 전체 다시 적재를 실행해야 합니다.
