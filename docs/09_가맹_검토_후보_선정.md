# 가맹 검토 후보 선정·점수·CSV

기준: 2026-10-30 현재 코드 · 화면 `/gap/{시군구코드}/candidates`

전체 체육시설 자료에서 스포츠 강좌이용권 가맹 목록과 연결되지 않은 시설을 추려, **어느 시설부터 가맹 여부와 운영 조건을 확인할지** 참고 순서를 만드는 기능입니다. 미가맹 확정 목록이나 AI가 예측한 가맹 성공 확률은 아닙니다.

## 사용 데이터와 사전 가공

| 원본·입력 | 활용 정보 | 가공 방식 |
|---|---|---|
| 전국체육시설현황 | 지역·시설명·주소·업종·유형·운영/삭제 상태·실내 여부·갱신일 | 지역·정규화한 이름·주소로 시설을 묶고 업종 규칙 적용 |
| 전국공공체육시설·개방학교 체육시설 | 공공시설·학교 공간과 운영 기록 | 전체 시설 목록 보충. 학교는 개방 기록의 기준연도 확인 필요 |
| 스포츠 강좌이용권 시설·이용현황 | 가맹시설 목록 | 전체 시설과 이름·주소·지역·전화번호로 연결 |
| 체육시설 안전점검정보 | 등급·점검일 | 같은 지역·이름·주소의 가장 최근 점검 기록 연결 |
| 체육시설 인접 대중교통 | 정류장·도보 시간 | 같은 지역·이름·주소에 연결된 정류장 중 최소 도보 시간 사용 |
| 서비스의 시설 이용 희망 등록 | 시설별 등록 건수 | 공개 데이터와 별도로 합산해 점수에 가산 |

업종의 아동 강좌 적합성과 추정 종목은 [업종 대응 규칙 · 1행](/home/yojun/SportsBridge/data/mappings/category_rules.json:1)에서 정합니다. 예를 들어 수영장업은 적합 업종·수영으로, 당구장업은 가능성 낮은 업종으로 분류합니다. 실제 수업 개설 여부를 확인한 결과가 아닙니다.

## 후보를 추리는 순서

1. **현재 데이터 버전과 선택 지역을 고릅니다.** 전체 시설 목록 중 가맹시설 연결값이 없는 시설을 읽습니다.
2. **기본 운영 조건을 적용합니다.** 삭제 표시가 없고 상태가 `정상운영` 또는 `개방(연도 확인 필요)`인 시설만 남깁니다. 모든 미확인 상태를 운영 중이라고 가정하지 않습니다.
3. **업종 범위를 정합니다.** 기본으로 적합 업종과 적합성 미확인 업종을 포함합니다. 당구·골프 등 가능성 낮은 업종은 별도 선택해야 포함되며 적합성 가점은 없습니다.
4. **화면 필터를 적용합니다.** 업종, 시설명 부분 일치, 안전점검 양호 여부로 좁힙니다. 검토 종목 선택은 후보를 그 종목으로 제한하지 않고 종목 일치 가점에 사용합니다.
5. **점수와 설명을 만듭니다.** 아래 가점·감점을 합산하고 시설 이용 희망 가점을 더합니다. 점수 높은 순, 동점이면 시설명 순으로 정렬합니다.
6. **확인할 항목을 붙입니다.** 실제 가맹 여부, 유사 시설, 운영 상태, 안전 자료, 연락처 등을 함께 표시합니다. 화면은 50곳씩 불러오고 ‘더 보기’로 이어집니다.

## 점수 계산

| 기준 | 점수 | 의미 |
|---|---:|---|
| 아동 강좌 적합 업종 | +3 | 업종 규칙상 적합으로 분류 |
| 업종 적합성 미확인 | +1 | 적합 여부를 판단하기 어려운 업종 |
| 검토 종목과 추정 종목 일치 | +3 | 업종·시설 유형에서 추정한 종목과 입력 종목이 같음 |
| 안전점검 양호 | +2 | 연결된 공개 점검 등급이 양호 |
| 그 외 점검 기록 있음 | +1 | 양호·주의 등 아래 감점 등급에 해당하지 않는 기록 존재 |
| 주의·수리필요·사용중지 | −3 | 연결된 점검 기록에 해당 등급이 있음 |
| 정류장 도보 5분 이내 / 10분 이내 | +2 / +1 | 원본의 초 단위 값으로 비교하며 중복 가산하지 않음 |
| 실내 | +1 | 자료의 실내 여부가 정확히 실내인 경우 |
| 정보 갱신 연도가 2025년 이후 | +1 | 현재 연도에 따라 바뀌는 최근 1년 기준이 아닌 고정 기준 |
| 시설 이용 희망 | 1건당 +1, 최대 +3 | 등록 건수이며 고유 이용 인원은 아님 |

예를 들어 적합 업종 3점, 안전 양호 2점, 도보 5분 이내 2점, 실내 1점, 2025년 이후 갱신 1점에 희망 등록 1건이면 총 **10점**입니다. 검토 종목도 일치하면 3점이 더해집니다. 등록 10건이 있어도 등록 가점은 3점입니다.

## 연결·점수 결과를 읽는 방법

- 가맹 목록 연결은 지역 내 이름·주소 일치 → 양쪽에서 유일한 이름 일치 → 유일한 전화번호 일치 순으로 수행합니다. 연결되지 않아도 같은 시설일 수 있습니다.
- 확정 연결이 안 된 경우, 이름의 두 글자 조각 유사도 또는 이름 일부가 겹치고 좌표가 가까운 조건으로 유사 후보를 남깁니다. 이 후보에 포함된 시설에는 ‘동일 시설일 수 있음’을 표시합니다.
- 안전점검은 공개된 과거 기록입니다. 자료 없음이 위험·미점검 확정은 아니고, 양호도 현재 안전을 보장하지 않습니다.
- 교통 점수는 원본 초 단위로 계산하지만 화면은 분으로 반올림합니다. **0분은 반올림 결과일 수 있으며**, 도보 자료 없음은 접근 불가가 아닙니다.
- 점수는 확인 우선순위입니다. 실제 아동 강좌 운영 가능성·가맹 승인·정책 효과·잔여석을 확정하지 않습니다.

## CSV 결과와 범위

CSV에는 순위·점수·시설 정보·추정 종목·안전·교통·점수 근거·확인 필요·출처를 담습니다. 한글 호환을 위한 UTF-8 BOM을 붙이고, 스프레드시트 수식으로 읽힐 수 있는 문자열 앞에 작은따옴표를 붙입니다.

CSV는 최대 2,000곳이며 종목·업종·적합성·안전 필터를 적용합니다. **현재 CSV API는 시설명 검색값을 받지 않아, 화면에서 이름 검색을 했더라도 CSV에는 그 검색이 적용되지 않습니다.** 따라서 화면에 보이는 행과 다운로드 행이 항상 같지는 않습니다.
