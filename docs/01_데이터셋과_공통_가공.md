# 데이터셋과 공통 가공

기준: 2026-10-30 현재 코드. 공공 CSV를 지역·시설·강좌 단위로 정리해, 검색과 현황 분석에서 함께 사용하는 조회 데이터를 만드는 기능입니다.

## 사용하는 원본 10종

데이터 이름과 제공기관은 코드의 출처 등록소 기준입니다. 원문 주소도 아래 관련 코드에서 확인할 수 있습니다.

처음 5종은 필수이며, 나머지 5종이 없으면 해당 보충 정보 없이 처리합니다. 자료는 자동으로 외부에서 내려받지 않고 서버의 원본 폴더에서 읽습니다.

## 처리 흐름

`CSV 읽기 → 표기 통일 → 지역·시설·강좌 묶기 → 시간표·안전·교통 연결 → 지역별 집계 → 조회 데이터 저장`

### 1. CSV를 읽고 값의 형식을 맞춥니다

- 같은 이름의 `.csv`가 있으면 먼저 읽고, 없으면 `.csv.gz`를 압축 해제하면서 읽습니다. 한글 파일명의 NFC/NFD 차이는 파일을 찾을 때 통일합니다.
- `UTF-8-SIG`로 읽어 BOM을 처리하고, 열 이름·값 앞뒤 공백을 제거합니다. 다른 문자 인코딩으로 자동 재시도하지는 않습니다.
- 숫자는 쉼표를 제거해 변환하고, 빈칸·변환 불가 값은 미확인으로 둡니다. 다만 대상·수급·신청 인원 합산에서는 없는 값을 0으로 처리합니다.
- `16:30`은 하루 시작부터 990분으로 바꿉니다. 요일은 월~일 순서의 7자리 0/1 문자열만 해석합니다. 자릿수가 모자란 값은 임의로 보완하지 않습니다.
- 좌표가 없거나 한국 범위 밖이면 위치 정보를 저장하지 않습니다. 좌표가 없다고 시설 자체를 제외하지는 않습니다.

### 2. 지역과 시설을 같은 기준으로 묶습니다

- 지역별 활용정보의 앞 5자리 시군구 코드를 기준으로 삼습니다. 다른 자료는 코드, 시도·시군구명, 미리 정한 별칭, 상위 시 코드 순서 등으로 맞춥니다.
- 일부 행정구역은 기존 지역에 근사 대응합니다. 끝내 연결하지 못하면 원래 코드를 남기고 미연결 기록에 모읍니다.
- 시설명은 공백·괄호 부가설명·법인 표기 등을, 주소는 괄호 내용·일부 층/호 표기·공백 등을 정리합니다. 전화는 숫자만 남깁니다.
- `지역 + 정리한 시설명 + 정리한 주소`가 같으면 같은 시설로 묶고 종목·전화 등 빈 정보를 보충합니다. 원본이 다르게 적힌 같은 시설까지 완벽히 합쳐지는 것은 아닙니다.
- 가맹시설 목록에는 **시설 원본과 이용현황의 시설을 함께 포함**합니다. 따라서 과거 이용 기록만 있는 시설도 포함될 수 있습니다.

### 3. 강좌의 월별 이력과 시간표를 연결합니다

- 이용현황의 `COURSE_NO`를 강좌 ID로 사용합니다. 강좌연월별 신청 인원·금액을 모아 첫/마지막 기록월, 신청 합계, 마지막 기록월 신청 인원을 만듭니다.
- 같은 강좌번호·같은 월이 반복되면 강좌의 월별 값은 뒤의 행으로 덮어씁니다. 반면 시설의 월별 신청 합계는 읽은 행을 계속 더합니다. 모든 종류의 중복을 일괄 제거하는 방식은 아닙니다.
- 별도 강좌표에서 `종목코드 + 정리한 강좌명`이 같은 후보를 찾고, 가격·연도가 맞는 후보를 우선합니다. 그 안에서 최신 연도·긴 설명 순으로 하나를 고릅니다.
- 서로 다른 시간표가 여러 개 남으면 하나를 표시하되 **시간표 연결 모호 상태와 후보 수**를 남깁니다. 후보가 없거나 요일·시각을 해석하지 못하면 시간표가 비어 있을 수 있습니다.
- 월 수강료는 이용현황의 가장 최근 확인 가능한 금액입니다. 원본에 단위 표기가 없어 이를 월 수강료로 해석했다는 메모를 남깁니다.

### 4. 전체 시설에 보충 정보를 붙입니다

- 전국체육시설·공공체육시설·개방학교를 같은 시설 키로 통합합니다. 업종·시설유형은 별도 규칙표로 아동 강좌 적합성 및 추정 종목에 대응시킵니다.
- 학교의 개방시간·종목은 원문을 보관합니다. 검색에 필요한 시간 구간 해석은 공공 운동 공간 조회 단계에서 추가로 합니다.
- 안전정보는 `지역 + 시설명 + 주소`가 같은 기록 중 가장 최근 점검일 기준으로 연결합니다.
- 교통정보도 같은 시설 기준으로 묶고, 여러 정류장이 있으면 원본의 도보시간이 가장 짧은 하나를 연결합니다. 새로운 보행 경로를 계산하지는 않습니다.

### 5. 가맹 목록과 전체 시설 목록을 연결합니다

1. 같은 지역에서 이름·주소가 일치하면 연결합니다.
2. 아니면 지역 안에서 이름이 유일한지, 또는 전화번호가 유일한지를 확인합니다.
3. 확정하지 못하면 이름의 두 글자 조각이 겹치는 정도를 비교합니다. 이름이 일부 겹치고 좌표가 가까운 경우도 참고해 유사 후보를 최대 3개 남깁니다.

이 결과는 **두 자료의 동일 시설 연결 여부**입니다. 미연결은 실제 미가맹 판정이 아니며, 유사 후보는 동일 시설로 확정된 결과가 아닙니다.

## 만들어지는 결과와 조회 경로

| 결과 | 저장 위치 | 사용처 |
|---|---|---|
| 지역 기준·대상자·수급자 | `region_stats` | 지역 선택, 수급률·시설 비율 |
| 가맹시설·강좌·시설 월별 신청 | `facilities_voucher`, `courses`, `usage_monthly` | 강좌·시설 검색과 지역 현황 |
| 전체 시설과 목록 연결 결과 | `facilities_all`, `match_results` | 가맹 검토·공공 운동 공간 |
| 시군구별 시설·종목·시간대 집계 | `gap_aggregates` | 전국 비교·지역별 지표 |

원본 확인·교체와 전체 재반영은 `/data`, 출처·파일 상태는 `GET /api/data/sources`, 사용 중인 버전·지역 목록은 `GET /api/metadata`에서 다룹니다. 전체 재반영은 `POST /api/data/import`가 공통 가공을 실행합니다.

새 조회 데이터는 임시 컬렉션에 저장한 뒤 컬렉션을 교체하고 사용 중인 버전을 바꿉니다. **각 컬렉션 교체는 별개 작업**이므로 데이터베이스 전체의 한 번에 되돌릴 수 있는 트랜잭션으로 보장되는 것은 아닙니다.

## 해석할 때 주의할 점

- 집계 시작월은 자료의 최신 강좌월에서 12개월 전이며, 시작월과 최신월을 모두 포함합니다. 예를 들어 2025-08~2026-08은 달력상 13개월입니다. 내부 필드 이름이 `last12mApplicants`여도 화면의 실제 집계기간을 기준으로 읽습니다.
- 신청 합계는 월별·강좌별 **연인원**입니다. 같은 사람이 반복 포함될 수 있고, 시설 이용 희망 등록이나 현재 대기 인원과는 다릅니다.
- 집계기간에 기록이 있다고 현재 모집·영업·가맹 유지가 확인된 것은 아닙니다. 정보 미확인과 숫자 0도 구분해야 합니다.
- 이 공통 가공은 정해진 규칙으로 실행합니다. AI 추출이나 실제 가맹 승인·수강 신청을 수행하는 단계가 아닙니다.
