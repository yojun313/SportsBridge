# 이용자 지역 현황

기준: 2026-10-30 현재 코드 · 화면 `/user/region`

선택한 시군구에 어떤 스포츠 강좌이용권 시설·강좌 기록이 있는지 요약하는 기능입니다. **공개 자료의 공급 현황과 서비스에 등록된 희망 의견을 나란히 보여줍니다.** 현재 모집 여부를 조회하거나 AI로 수요를 예측하는 기능은 아닙니다.

## 입력과 사용 데이터

입력은 시도·시군구입니다. 시군구를 바꾸면 해당 지역 코드를 서버에 전달합니다. 선택 지역은 브라우저에 저장하고, 주소의 `region` 값이 있으면 그 값을 먼저 사용합니다.

| 데이터 | 활용하는 정보 | 화면에서의 용도 |
|---|---|---|
| 지역별 스포츠 강좌이용권 활용정보 | 지역 코드·인구·대상자·수급자 | 지역 구분, 대상자 대비 시설 수와 전국 순위의 기준 |
| 스포츠 강좌이용권 시설 | 시설명·주소·종목 | 시설 목록의 기본 정보 |
| 스포츠 강좌이용권 이용현황 | 강좌번호·시설·종목·강좌연월·신청 인원 | 강좌·시설의 기록 여부, 종목별 강좌 수, 시설 표시 순서 |
| 스포츠 강좌이용권 이용시설 강좌 | 강좌명·종목·요일·시작·종료 시각 | 이용현황 강좌에 연결할 시간표 |
| 스포츠 강좌이용권시설 인접 대중교통 | 연결된 정류장·도보 시간 | 시설 카드의 정류장 도보 시간 |
| 전국체육시설현황 등으로 구성한 전체 시설 목록 | 운영 상태·업종·가맹 목록 연결 여부 | 지역 설명에 포함되는 가맹 확인 후보 수 |
| 이용자가 직접 등록한 희망 강좌·시설 의견 | 지역·희망 종목·등록 건수 | 희망 강좌 등록 건수와 시설 이용 희망 건수 |

공개 CSV의 정리·시간표 연결은 [공통 데이터 가공](01_데이터셋과_공통_가공.md)에서 먼저 수행합니다. 이 화면을 열 때 원본 CSV를 다시 파싱하지는 않습니다.

## 처리 흐름

1. **현재 사용 중인 데이터 버전을 찾습니다.** 선택한 시군구의 미리 계산된 지역 통계를 읽습니다. 인구·대상자·수급자와 시설·강좌 수, 저녁 강좌 비율 등이 여기에 들어 있습니다.
2. **집계기간을 적용합니다.** 전체 이용현황의 최신 강좌월에서 12개월 전을 시작월로 잡고, 시작월 이후 강좌 기록을 사용합니다. 지역마다 오늘 날짜를 기준으로 기간을 새로 계산하지 않습니다.
3. **종목·시간·요일 분포를 만듭니다.** 해당 지역의 기간 내 강좌를 읽어 종목별로 세고, 연결된 수업 시간표를 시작 시각·요일별로 집계합니다.
4. **시설 목록을 읽습니다.** 공개 가맹시설·이용현황에서 통합한 시설을 기간 내 수강 신청 누계가 많은 순으로 가져옵니다. 이 목록에는 기간 내 기록이 없는 시설도 포함될 수 있습니다.
5. **희망 의견을 별도로 합산합니다.** 지역의 희망 강좌 등록 건수와 시설 이용 희망 건수를 읽습니다. 공개 수강 신청 인원과 더하거나 같은 숫자로 취급하지 않습니다.
6. **설명 문장과 화면을 구성합니다.** 정해진 문장에 통계값을 넣어 지역 설명을 만들고, 통계 카드·막대그래프·시설 카드로 표시합니다. AI 호출은 없습니다.

## 무엇을 계산하고, 무엇을 읽어 오는가

| 항목 | 계산 방식 |
|---|---|
| 강좌 기록이 있는 가맹시설 수 | 데이터 반영 시, 시설의 마지막 기록월이 집계 시작월 이상이면 1곳으로 계산 |
| 집계기간 내 강좌 수·종목 수 | 기간 내 강좌를 세고, 서로 다른 종목의 가짓수를 계산 |
| 저녁 강좌 비율 | 시간표가 있는 기간 내 강좌 중 18시 이후 시작 수업이 하나 이상 있는 강좌 수 ÷ 시간표가 있는 강좌 수 |
| 대상자 1,000명당 시설 수·전국 순위 | 대상자 대비 시설 수를 미리 계산하고 값이 적은 지역부터 순위를 매김 |
| 종목별 막대그래프 | 조회 시 해당 지역 강좌를 종목별로 집계하고, 상위 10개 표시 |
| 시작 시각 막대그래프 | 조회 시 강좌별 시작 시각을 2시간 구간으로 분류. 같은 강좌가 같은 구간에 여러 번 있어도 그 구간에서는 한 번만 계산 |
| 요일 막대그래프 | 조회 시 시간표의 수업 일정을 요일별로 계산. 같은 강좌의 여러 일정이 반복 포함될 수 있음 |
| 희망 강좌·시설 이용 희망 | 서비스에 저장된 등록 기록을 지역별로 합산. 공개 데이터 버전과 별도로 누적된 의견 |

시작 시각 그래프의 구간은 06·08·10·12·14·16·18·20·22시입니다. 06시 이전은 첫 구간, 22시 이후는 마지막 구간에 포함됩니다. 저녁 비율과 주말 비율의 분모는 전체 강좌가 아니라 **시간표가 확인된 강좌**입니다.

## 간단한 예시

가정으로, 기간 내 강좌가 10개이고 그중 시간표가 있는 강좌가 4개라고 하겠습니다. 이 4개 중 2개에 18시 이후 시작하는 수업이 있으면 저녁 강좌 비율은 `2 ÷ 4 = 50%`입니다. 나머지 6개를 낮 수업으로 가정하지 않습니다.

같은 지역에 희망 강좌 등록이 3건 있더라도 강좌 수가 13개가 되거나 수강생이 3명 늘어나는 것은 아닙니다. 공급 기록과 이용자 의견은 서로 다른 지표입니다.

## 결과 해석 시 주의점

- 시작월과 마지막 월을 모두 포함합니다. 예를 들어 `2025-08~2026-08`은 13개 달을 포함하므로 내부 필드명에 `12m`이 있어도 단순히 최근 12개월로 읽지 않습니다.
- 시설의 **기간 내 기록 있음 / 없음 / 기록 미확인**은 강좌 이용 이력에 따른 상태입니다. 폐업·가맹 해제·현재 모집·잔여석을 판정한 상태가 아닙니다.
- 수강 신청 누계는 월별·강좌별 신청 인원의 합계이며 동일인이 반복 포함될 수 있습니다. 희망 등록 건수도 실인원이나 실제 수강 신청 건수가 아닙니다.
- 지역 API는 시설을 최대 60곳 전달하고, 이 화면은 그중 최대 24곳을 카드로 표시합니다. 상단의 지역 전체 시설 수와 카드 개수가 다를 수 있습니다.
- 수치가 없으면 비율을 계산하지 않습니다. 전국 순위는 특정 지표가 낮은 순서이며 종합 서비스 평가나 부족 원인 분석이 아닙니다.
