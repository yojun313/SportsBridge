# 협의 계획서 생성·AI 문장 정리·출력

기준: 2026-10-30 코드 · 화면: `/scenario/plan`

선택한 지원 방안의 입력값과 계산 결과를 협의용 문서 초안으로 정리합니다. 기본 서식은 AI 없이 작성하며, 설정이 켜져 있으면 같은 계산 근거로 AI 문장 정리를 요청할 수 있습니다.

## 입력과 사용하는 데이터

| 입력·자료 | 활용 |
|---|---|
| 브라우저에 저장한 시나리오 | 수요 집단·대상 강좌·개선 조치·정원·비용·예산·출처 상태 |
| 비교 화면에서 선택한 조치 ID | 어떤 지원 방안을 문서화할지 지정 |
| 시뮬레이션 엔진의 재평가 결과 | 배정 인원·집단별 배정·비용 합계·이용 불가 사유 |
| 지역별 스포츠 강좌이용권 활용정보에서 가공한 지역 정보 | 시군구 코드를 읽기 쉬운 시도·시군구 이름으로 표시 |
| 현재 사용 데이터 버전 | 문서와 계산 근거에 참고 버전으로 표시 |

강좌·시설·시간표의 원본 CSV를 새로 파싱하거나 현재 운영 상태를 다시 조회하는 기능은 아닙니다. 공개 자료에서 불러온 정보와 담당자가 작성한 시나리오를 사용합니다.

## 문서가 만들어지는 순서

1. **작성 내용과 선택을 읽습니다.** 브라우저의 `vgp_scenario`와 `vgp_selected_bundle`에서 시나리오·선택 조합을 읽어 서버에 보냅니다.
2. **선택 조합을 다시 계산합니다.** 엔진이 해당 조치를 적용한 배정·비용·연결 불가 결과를 만듭니다.
3. **계산 근거를 묶습니다.** `build_facts`가 지역 이름·작성일·버전·수요·선택 조치·배정·확인 필요·가정값을 구조화된 JSON으로 정리합니다.
4. **문서 초안을 작성합니다.** 기본 서식 또는 AI 문장 정리 중 요청한 방식으로 마크다운 문서를 만듭니다.
5. **근거 대조 결과와 함께 보여줍니다.** 문서 왼쪽에는 초안, 오른쪽에는 확인 필요·가정값 사용 목록과 계산 근거를 표시합니다.

현재 버전 표시는 문서 생성 시 서버의 사용 버전입니다. 시나리오를 과거에 불러왔다면 입력된 강좌 정보까지 자동으로 최신화되는 것은 아니므로 데이터가 바뀐 뒤에는 입력도 확인해야 합니다.

## 기본 서식과 AI 문장 정리의 차이

| 방식 | 처리 |
|---|---|
| 기본 서식 | `POST /api/scenarios/plan-draft`가 목적, 수요 집단, 선택 조치, 모델상 결과, 확인 필요, 가정값, 다음 행동을 정해진 순서로 채웁니다. AI 호출은 없습니다. |
| AI 문장 정리 | `POST /api/llm/plan-doc`가 같은 계산 근거를 AI에 보내고 그 안의 내용만으로 초안을 작성하도록 요청합니다. 숫자·이름 대조에서 문제가 나오면 한 번 다시 생성하며, 계속 문제가 있거나 응답을 거부하면 초안을 제공하지 않습니다. |

AI 방식은 기능 설정과 호출 예산 제한을 따릅니다. AI가 정원·조치 비용·배정 인원을 새로 계산하는 것은 아니며, 입력 조건의 실제 확보 가능성을 확인하지도 않습니다.

## ‘숫자·이름 근거 대조’가 확인하는 범위

- 문서의 숫자를 계산 근거 안에 나타난 숫자와 비교합니다. 문서 구조의 번호 등 일부 숫자는 허용합니다.
- 이름 검사는 선택 조치가 있을 때 근거의 시설·집단 이름이 문서에 나타나는지 확인하는 수준입니다. 새로 등장한 모든 고유명사를 찾아내는 검사는 아닙니다.
- 기본 서식의 대조 문제는 화면에 경고로 표시합니다. AI 초안은 재생성 후에도 문제가 있으면 오류로 반환합니다.

따라서 ‘대조 완료’는 **문서 전체의 사실 확인·시설 운영 확인·정책 효과 검증·사업 승인**을 뜻하지 않습니다. 입력 자체가 가정이면 문서 결과도 가정에 따른 계산입니다.

## 작은 예시와 확인할 점

수영 희망 집단 8명, 가맹 협의 비용 20만 원, 강좌 신설 비용 60만 원을 입력하고 두 조치를 선택했다고 가정합니다. 시간·연령·정원 등 조건이 맞아 엔진이 8명을 배정했다면 초안은 ‘총 수요 8명, 모델상 배정 가능 8명, 조치 비용 합계 80만 원’과 선택 조치·가정값을 문장으로 정리합니다. 실제 가맹 승인이나 8명의 실제 참여를 의미하지 않습니다.

문서에는 미확인 비용·정원·가맹 상태·출석 규칙과 가정으로 표시한 비용·강좌 정원을 함께 확인할 수 있습니다. 비용이 미확인이면 표시된 합계를 전체 확정 비용으로 해석하지 않습니다.

문서 생성은 선택 조합을 직접 평가하며, 조합 비교 단계의 선행·동시 선택 불가 조건을 다시 심사하는 기능은 아닙니다. 예산 초과·비용 미확인 조합도 검토용으로 선택할 수 있으므로 정상 비교 결과에서 선택하고 계획서 사용 전 조건을 다시 확인해야 합니다.

## 결과 활용

- **마크다운 복사**: 문서 원문을 복사해 편집기에 붙여 넣습니다.
- **계산 근거(JSON) 복사**: 입력·선택·계산 결과와 확인 상태를 구조화된 형태로 복사합니다.
- **인쇄**: 브라우저 인쇄 창을 열어 인쇄하거나 PDF로 저장합니다.

모두 협의 준비용 초안이며 공식 신청·가맹 처리·문서 제출을 자동 실행하지 않습니다. 화면에는 ‘자동 생성 초안, 담당자 검토 전’을 표시합니다.
