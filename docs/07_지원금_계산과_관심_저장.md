# 지원금 계산과 관심 강좌 저장

기준: 2026-10-30 코드 · 화면: `/user/planner`

강좌를 검색해 월 수강료를 적용하고, 입력한 지원 기간·월 한도로 예상 지원액과 본인부담금을 계산합니다. 강좌 검색은 MongoDB의 공개 자료를 조회하고, 금액 계산과 관심 강좌 관리는 브라우저에서 처리합니다.

## 사용 순서

1. **계산할 강좌 검색**에서 시도·시군구를 선택합니다. 종목이나 시설명·강좌명을 입력하고 **강좌 검색**을 누릅니다.
2. 결과의 **수강료 적용**을 누르면 계산기의 월 수강료가 채워지고 계산됩니다. 저장한 강좌에도 같은 버튼이 있습니다. 수강료가 미확인인 강좌는 적용할 수 없으며, 시설에 확인한 금액을 직접 입력합니다.
3. 지원 유형·월 지원 한도·지원 시작 월·전체 개월 수·계산 기준 월을 선정 안내문에 맞게 확인한 뒤 **지원금 계산**을 누릅니다.
4. 한 번 계산한 뒤에는 값을 바꾸면 결과를 다시 계산합니다. 입력을 비우거나 잘못된 값을 넣으면 이전 결과를 제거하고 오류를 표시합니다.

## 입력과 데이터

| 입력·자료 | 사용 방법 |
|---|---|
| 지원 유형·월 한도 | 유형별 기본값은 유·청소년 105,000원, 장애인 110,000원이며 선정 안내문에 맞게 한도를 수정할 수 있습니다. 유형을 바꾸면 해당 기본 한도를 다시 적용합니다. |
| 지원 시작 월·개월 수 | 첫 방문 시 현재 연도 1월·12개월을 표시합니다. 실제 선정 기간에 맞게 수정합니다. 개월 수는 1~12의 정수입니다. |
| 계산 기준 월 | 한국 시간의 현재 월이 기본값입니다. 이 월을 포함해 계산하므로 이번 달에 이미 결제했으면 다음 달로 바꿉니다. 재방문 시 현재 월로 다시 설정합니다. |
| 강좌 월 수강료 | 0~5,000,000원 범위의 정수입니다. 0원은 무료이며 빈칸은 미입력입니다. 지원 한도도 같은 금액 범위를 적용합니다. |
| 검색 강좌 | 현재 사용 중인 버전의 `courses`, `facilities_voucher`를 연결합니다. 마지막 기록 월이 집계 시작 월 이후인 강좌를 조회합니다. |
| 저장 강좌 | 강좌 찾기에서 저장한 이름·시설·종목·시간·수강료의 복사본입니다. 저장 후 자동으로 최신화하지 않습니다. |

실제 카드 잔액·결제 내역·지원 자격은 조회하지 않습니다. 매월 동일한 가격으로 한 강좌를 이용하는 경우를 계산합니다. 여러 강좌의 합산 결제나 월별로 다른 수강료를 계산하지 않습니다.

## 검색 로직

`GET /api/user/planner/courses`는 지역과 선택 종목, 집계 시작 월로 강좌를 필터링한 뒤 시설 정보를 연결합니다. 검색어는 강좌명·시설명에 부분 일치시킵니다. 정규식 특수문자는 일반 문자로 처리합니다. 최신 기록 월·강좌 ID 순으로 정렬해 총 건수와 20개씩의 결과를 반환합니다.

화면에 필요한 강좌 ID·이름·시설·주소·종목·시간표·수강료·마지막 기록 월만 반환합니다. 검색은 현재 모집·잔여석이나 유·청소년/장애인 유형별 결제 가능 여부를 확정하지 않습니다. 수강료가 미확인이면 0원으로 간주하지 않고 **수강료 확인 필요**로 표시합니다.

검색 조건을 바꾸면 기존 결과를 지웁니다. 여러 요청이 겹쳐도 마지막 요청의 결과만 표시합니다.

## 계산식

월을 연속된 정수로 바꿔 계산하므로 연도를 넘는 기간도 처리합니다.

- 종료 월 = 시작 월 + 전체 지원 개월 수 − 1
- 남은 개월 수 = `max(0, 종료 월 − max(기준 월, 시작 월) + 1)`
- 월 예상 지원액 = `min(월 수강료, 월 지원 한도)`
- 월 예상 본인부담금 = `max(0, 월 수강료 − 월 지원 한도)`
- 남은 기간 예상 지원액 = 남은 개월 수 × 월 예상 지원액
- 남은 기간 본인부담금 = 남은 개월 수 × 월 예상 본인부담금
- 남은 기간 수강료 = 예상 지원액 + 본인부담금

지원 시작 전이면 전체 개월 수가 남고, 지원 종료 후면 0개월입니다. 종료 후에도 월별 요금 비교는 표시하되 남은 기간 합계는 0원입니다. **지원 한도 합계**는 한도 × 개월 수이며, 수강료가 한도보다 낮을 때 실제 적용할 예상 지원액과 다릅니다. 차액을 현금·이월액으로 계산하지 않습니다.

## 계산 예시

| 조건 | 기준 월 포함 기간 | 월 예상 지원액 | 월 본인부담금 | 남은 기간 지원액 | 남은 기간 부담금 |
|---|---|---:|---:|---:|---:|
| 2026년 1월부터 12개월, 기준 10월, 한도 105,000원, 수강료 120,000원 | 3개월 | 105,000원 | 15,000원 | 315,000원 | 45,000원 |
| 같은 기간·한도, 수강료 80,000원 | 3개월 | 80,000원 | 0원 | 240,000원 | 0원 |
| 같은 기간·한도, 무료 강좌 | 3개월 | 0원 | 0원 | 0원 | 0원 |
| 같은 지원 기간, 기준 월 2027년 1월 | 0개월 | 월 요금 비교만 표시 | 월 요금 비교만 표시 | 0원 | 0원 |

## 브라우저 저장

- `sb_planner`: 마지막 정상 계산의 시작 월·개월 수·유형·한도·수강료를 저장합니다. 기존 버전의 `sup` 필드도 복원합니다. 기준 월은 저장값을 재사용하지 않고 매 방문 현재 월로 표시합니다.
- `sb_favorites`: 강좌 찾기에서 저장한 관심 강좌입니다. 개별 저장 해제와 모두 지우기가 가능하며 실제 수강 신청에는 영향을 주지 않습니다. 저장 강좌의 수강료도 계산기에 적용할 수 있습니다.
- 브라우저 저장소가 차단돼도 검색과 계산은 가능합니다. 저장 데이터 형식이 손상됐으면 예외를 처리해 화면 전체가 중단되지 않게 합니다.

다른 기기·브라우저와 자동 동기화하지 않습니다. 사업 연도별 지원 한도와 기간, 실제 요금은 선정 안내문과 공식 사이트에서 확인해야 합니다.
