# 아이디어4 — 스포츠브릿지 (구 빈칸 복구 플래너)

작성일: 2026-09-18 · 작성: Claude · 상태: 아이디어2·3 통합 + LLM 고도화 설계, 원본 CSV·개발 전

> **"이용권을 받아도 쓸 곳이 없는 지역에서, 어느 시설을 가맹시키고 어떤 수업을 열고 무엇을 확인해야 운동 기회가 생기는지 — 진단부터 협의 문서까지 한 번에."**

지자체·공단·복지기관 담당자를 위한 **스포츠강좌이용권 공급 공백 복구 플래너**입니다. 코드명 `voucher-gap-planner`.

## 아이디어2·3을 왜 합치는가

두 문서는 같은 문제(공급 부족)를 서로 다른 단계에서 다루고 있었습니다.

| | 아이디어2 운동권 복구소 (Codex) | 아이디어3 가맹 빈칸 지도 (Claude) | 아이디어4에서 |
|---|---|---|---|
| 답하는 질문 | "이 수요 집단을 위해 어떤 조치 조합이 필요한가?" | "어느 지역이 비어 있고, 어느 비가맹 시설부터 접촉할까?" | 두 질문을 한 흐름으로 연결 |
| 시작점 | 담당자가 수요·조치를 직접 입력 | 공공 데이터만으로 자동 진단 | 자동 진단이 입력을 미리 채우고, 담당자는 확인·수정만 |
| 핵심 계산 | 최대유량 배정 + 조치 조합 완전탐색(의존성) | 시군구 3축 진단 + 비가맹 후보 순위 | 둘 다 유지. 후보 발굴 결과가 조치 후보의 초기값 |
| 결과물 | 협의용 계획서 | 후보 목록 CSV, 사업자용 브리프 | 계획서·제안서를 LLM이 초안 작성, 숫자는 엔진 값만 |
| 약점 | 입력 준비 부담이 큼. 정원·비용 없으면 빈 화면 | 조합·의존성 계산이 없어 "그래서 뭘 하나"가 약함 | 서로의 약점을 보완 |
| 데이터 | 80·74·05·64·06·26 | 26·80·74·64·05·73·19·34·08 | 합집합 |

즉 **아이디어3 = 파이프라인의 1·2단계, 아이디어2 = 3·4단계**입니다.

```text
① 공백 진단 (3)  →  ② 후보 발굴 (3)  →  ③ 수요·조치 시뮬레이션 (2)  →  ④ 협의 계획·문서 (2)
        └──────────── LLM: 비정형 텍스트 구조화 · 매칭 판정 · 자연어 시나리오 · 문서 초안 · 설명 ────────────┘
```

## LLM으로 무엇이 달라지는가

아이디어2·3이 공통으로 막혔던 지점은 **"원본에 없는 정보"**였습니다. 강좌 대상 연령·출석 규칙·수준은 74번의 자유 텍스트 설명에만 있고, 가맹시설과 전체 시설의 동일 여부는 이름·주소 표기 차이로 자동 판정이 안 되며, 담당자는 시나리오를 표로 입력하기 번거롭습니다. Claude API는 정확히 이 세 곳에 씁니다.

1. **비정형 → 정형**: 강좌 설명에서 연령·수준·출석규칙·셔틀 여부를 스키마로 추출 (Batch, 검토 큐).
2. **애매한 매칭 판정**: 규칙으로 못 가른 시설 쌍만 LLM이 동일/상이/불명 판정, 사람이 최종 확인.
3. **자연어 시나리오**: "센터 A 아이들 8명, 수영, 화목 4~6시, 예산 80만" → 도구 호출로 시나리오 생성·엔진 실행·결과 설명.
4. **문서 초안**: 엔진 결과(JSON)만 근거로 협의 계획서·가맹 제안서 작성. 문서 안 모든 숫자가 근거 JSON에 있는지 후검증.
5. **설명·반사실**: "가맹만 하면 왜 효과가 없는가"를 계산 추적에서 설명.
6. **복구 에이전트**: 위 기능을 도구로 묶어 담당자가 질문 한 번으로 진단→후보→조합 계산을 타게 하는 도구 호출 에이전트. 결정론적 계산은 도구 안 코드가, 서술만 모델이. 인용·성과 단정 가드, SSE 대시보드, 평가 하네스 포함 (05 문서).

원칙: **숫자와 판정은 결정적 엔진이 만들고, LLM은 텍스트를 구조로 바꾸거나 구조를 텍스트로 바꾸는 일만 합니다.** 모든 LLM 산출물은 `llm_extracted` 출처 표시와 신뢰도, 검토 상태를 가집니다. 상세는 [02_LLM_활용_설계.md](02_LLM_활용_설계.md).

## 정직하게 말할 수 있는 독창성

- 아이디어2·3 조사에서 **한국 이용권의 가맹·강좌·접근 조건을 연결해 공백 진단→후보 발굴→의존적 조치 조합→협의 문서까지 다루는 공개 서비스는 확인하지 못했습니다.** 가장 가까운 개념적 경쟁자는 Sport England 시설계획모델(수요·공급 계획)과 바우처 행정 관리 솔루션이며, 실제 대체 수단은 엑셀·GIS·담당자 협의입니다.
- LLM으로 비정형 강좌 설명을 구조화해 정책 시뮬레이션 입력으로 쓰는 조합은 검색에서 발견하지 못했으나, 기법 자체(정보 추출, 엔티티 매칭)는 일반적입니다. **차별성은 기법이 아니라 업무 흐름과 출처 관리의 결합**입니다.
- "세계 최초", "대체 불가능"은 보증하지 않습니다. 공단 내부 도구, 지자체 용역 산출물은 확인할 수 없었습니다.
