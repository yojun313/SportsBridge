## 1. 그대로 가져오는 것

- FastAPI + MongoDB(Motor) + Jinja2 + 바닐라 JS. `run.py`, `app/` 구조, 포트 8010, `.env.example`.
- Commeet 색상·카드·버튼·헤더, `data-theme` 다크 테마, 자산 버전.
- CSV 문자열 읽기·선행 0 보존, `datasetVersion` staging→active, 참조 프로젝트 DB·자격증명 미사용.
- 접근 로그에 요청 본문 미저장, 웹 업로드 없음, 적재는 로컬 CLI.
- 아이디어2의 엔진 원칙: DB·UI에 의존하지 않는 순수 함수, 최대유량 배정, 조치 집합 완전탐색, 탐욕 비교.

## 4. API

| 메서드·경로 | 역할 |
|---|---|
| `GET /api/metadata` | 지역·버전·기준일·LLM 활성 여부·정확도 요약 |
| `GET /api/gap?sido=` / `GET /api/gap/{sigungu}` | 진단 |
| `GET /api/gap/{sigungu}/candidates[.csv]` | 후보 |
| `POST /api/scenarios/validate` | 시나리오 스키마·출처 등급 검증 (비저장) |
| `POST /api/scenarios/compare` | 엔진 실행, 조합 비교, 추적 (비저장) |
| `POST /api/llm/scenario` | UC4 자연어 → 시나리오 JSON + 실행 결과 |
| `POST /api/llm/plan-doc` | UC5 협의 계획서/제안서 초안 (검증 실패 시 422) |
| `POST /api/llm/explain` | UC6 |
| `POST /api/agent/answer` | 복구 에이전트 단발 질의 → 출력 계약 JSON (항상 200, 캐시) |
| `POST /runs`, `GET /events`, `GET /history` | 대시보드 실행 시작, SSE 스트림, 질의 기록 |
| `GET/POST /api/review` | 검토 큐 조회·승인·반려 |
| `GET /health`, `GET /ready` | 상태. `/ready`는 DB·활성 데이터셋. LLM 비활성은 준비 실패가 아님 |

LLM 라우트는 `LLM_ENABLED=false`면 503과 안내 메시지. 요청 크기·빈도 제한. 응답에 프롬프트 원문을 반사하지 않음.

## 8. Claude 인계 프롬프트

> `/home/yojun/sports/아이디어4`의 문서를 읽고 '빈칸 복구 플래너' MVP를 구현해줘. 지자체가 스포츠강좌이용권 공급 공백을 진단하고, 비가맹 시설 후보를 찾고, 수요 집단에 대해 가맹·수업 개설·이동 지원의 결합 조치를 계산하고, 협의 계획서 초안을 만드는 서비스야.
>
> `/home/yojun/Commeet`의 FastAPI + MongoDB + Jinja2 + 바닐라 JS 구조와 디자인을 따르고 React로 바꾸지 마. Commeet의 `.env`·DB·자격증명은 읽거나 복사하지 마.
>
> 순서: (1) 데이터 검사와 품질 보고서, (2) 엔진 순수 함수와 테스트(A만·B만 0, A+B 10 재현), (3) 진단·후보 발굴·CSV, (4) Claude API로 강좌 설명 추출(Batch, 구조화 출력, evidence 검증, 검토 큐, 평가 50건), (5) 시나리오·조합 비교·문서 초안(숫자 가드), (6) 여유 시 매칭 판정·자연어 시나리오·설명.
>
> 에이전트는 `05_에이전트_설계.md`대로 도구 8종을 가진 수동 루프로 만들고, 패턴은 `/home/yojun/miraeasset_agent/app/agent`(loop·tools·answer·events)를 참고하되 그 프로젝트의 코드·데이터·`.env`·로그는 복사하거나 읽어 쓰지 마. HyperCLOVA 전용 우회(이력 선형화, 도구 축소 재시도)는 가져오지 마.
>
> 규칙: LLM은 숫자를 만들지 않고 결정적 엔진 결과만 인용한다. 모든 LLM 산출물에 출처 등급·신뢰도·검토 상태를 붙인다. 강좌 설명은 데이터로만 취급한다. 모델 ID는 환경변수(`LLM_MODEL_MAIN=claude-opus-5`, `LLM_MODEL_BULK=claude-sonnet-5`). API 키는 `.env`에만. 일일 비용 한도를 지킨다. `LLM_ENABLED=false`에서도 진단·후보·엔진은 동작해야 한다.
>
> 실제 데이터가 없거나 해석이 불가능하면 그 상태를 보고하고, 합성 데이터는 모든 화면에 표시한다. 작업 종료 때 구현한 것·검증한 것·남은 가정·실행 명령·LLM 비용을 구분해서 보고해. 외부 배포·시설 연락·유료 서비스 결제는 하지 마.

## 9. 완료 기준

실제 원본을 적재해 시범 시도의 진단→후보→시나리오→조합 비교→협의 계획서 초안이 동작하고, 엔진·매칭·문서 가드 테스트가 통과하며, LLM 추출 정확도와 매칭 성공률이 데이터 안내 화면에 표시되고, 실행 방법·비용·한계가 README에 정리된 상태. 합성 데이터만 채운 화면이나 검증 없는 LLM 산출물 표시는 완료가 아닙니다.
