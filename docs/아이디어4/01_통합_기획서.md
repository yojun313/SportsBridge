# 빈칸 복구 플래너 — 통합 기획서

작성일: 2026-09-18 · 버전 0.1 · 상태: 아이디어2·3 통합안, 원본 CSV 검증 전

## 1. 한 문장 정의

**스포츠강좌이용권 공급이 비어 있는 지역을 공공 데이터로 진단하고, 비가맹 시설 후보를 찾고, 수요 집단에 대해 "가맹·수업 신설·이동 지원" 중 함께 시행해야 효과가 나는 조합을 계산해, 협의 계획서와 가맹 제안서 초안까지 만들어 주는 지자체·공단·복지기관용 웹 서비스.**

## 4. 4단계 파이프라인

### ① 공백 진단 (시군구 단위, 아이디어3)

| 축 | 계산 | 데이터 |
|---|---|---|
| 양 | 대상자 1,000명당 가맹시설 수, 수급자 대비 시설 수 | 26, 80 |
| 종목 선택권 | 가맹 강좌 종목 수, 상위 1개 종목 비중, 아동 적합 종목 유무 | 74, 05 |
| 시간 선택권 | 평일 18시 이후·주말 강좌 비율 | 74 |
| 연령 적합 (LLM 보강) | 초등 저학년·고학년 대상 강좌 비율 | 74 설명 → LLM 추출 |

상대 순위와 원 수치만 표시하고 "부족" 판정 단어를 쓰지 않습니다. 장애인 이용권은 31·30·04·07·29로 별도 탭.

### ② 후보 발굴 (시설 단위, 아이디어3)

```text
전체 체육시설 (64, 73, 19) − 가맹시설 (80, 31) = 비가맹 후보
  매칭: ID → 정규화 정확일치 → 블로킹 후 LLM 판정 → 사람 검토   (03 문서)
  필터: 업종·아동 적합성(LLM 분류), 안전점검 등급(34), 대중교통(08), 실내 여부(64)
  점수: 공개 규칙. 부족 종목 일치 + 접근성 + 공백 큰 지역
  출력: 후보 목록, 확인 필요 목록, CSV
```

후보는 "접촉할 가치가 있는 순서"이지 "가맹 성사 확률"이 아닙니다.

### ③ 수요·조치 시뮬레이션 (아이디어2)

- 입력: 익명 수요 집단(종목·가용시간·인원·이동 조건), 공급 옵션(기존 강좌 + 후보 시설), 개선 조치(가맹 협의·수업 신설·이동 지원)와 비용·정원·선행조건.
- ②의 후보와 ①의 부족 종목·시간대가 **조치 후보의 초기값**으로 자동 채워집니다. 담당자는 확인·수정만 합니다.
- 자연어 입력을 지원합니다: "센터 A 아이들 8명이 수영을 화목 4~6시에 하고 싶어. 예산은 80만 원" → LLM이 도구를 호출해 시나리오를 만들고 엔진을 실행합니다(02 문서 UC4).
- 계산: 수요→공급 최대유량 배정, 조치 집합(≤10) 완전탐색, 조치 간 선행·동시·배타 관계. 목표: 배정 가능 수요 최대화 → 비용 최소 → 조치 수 최소.
- 두 모드: **구조 탐색**(공공 데이터만, 정원 없음 → 연결되는 수요 유형 수만 표시) / **정원·비용 시뮬레이션**(입력 있을 때 사람 수 배정).
- 핵심 시연: A(가맹)만 → 효과 없음, B(개설)만 → 효과 없음, A+B → 효과. 단독 효과 순 탐욕 선택이 이 조합을 놓치는 것을 함께 보여줍니다.

### ④ 협의 계획·문서 (아이디어2 + LLM)

- 선택한 조합에 대해 근거(출처·기준일·확인자)와 미확인 조건을 정리합니다.
- LLM이 **엔진 결과 JSON만 근거로** 담당자용 협의 계획서, 시설용 가맹 제안서 초안을 작성합니다. 문서 안 모든 숫자·시설명이 근거 JSON에 존재하는지 코드로 검증하고, 없으면 초안을 반려합니다.
- 담당자가 확인 결과를 입력하면 재계산합니다. 시스템은 가맹·개설·연락을 대신 실행하지 않습니다.

## 5. 출처 등급 (모든 값에 붙는 표시)

| 등급 | 뜻 | 예 |
|---|---|---|
| `public` | 공공 데이터 원본 컬럼 | 강좌 시작시간, 시설 주소 |
| `llm_extracted` | LLM이 텍스트에서 추출, 미검토 | 설명에서 뽑은 대상 연령 |
| `llm_reviewed` | LLM 추출을 사람이 승인 | 검토 큐 통과 항목 |
| `confirmed` | 담당자가 시설·기관에 확인 | 정원 8석, 가맹 의향 있음 |
| `assumed` | 시연·계획용 가정 | 개설 비용 60만 원 |

정원·비용 확정 배정은 `confirmed`만, 화면 필터·진단은 `public`+`llm_reviewed`까지, `llm_extracted`는 "확인 필요"로 별도 표시. `assumed`가 섞인 결과는 "가정 의존"으로 표시하고 인쇄에도 남깁니다.

## 7. 시제품 범위

### P0 (제출 최소)

- 26·80·74·64·05 적재, 진단 3축(양·종목·시간), 후보 발굴(정확일치 매칭), CSV.
- 74 강좌 설명 LLM 추출(연령·출석규칙) + 검토 큐 + 정확도 보고.
- 시나리오 편집(표 입력), 엔진(최대유량 + 조합 탐색), A/B/A+B 합성 시연.
- 협의 계획서 초안 생성 + 숫자 검증.
- 데이터 안내 화면. 시범 범위 시도 1개, 종목 1~2개.

### P1

- 애매 매칭 LLM 판정, 시설 업종·아동 적합성 분류, 34·08·06 결합.
- 자연어 시나리오 입력(도구 호출).
- 결과 설명·반사실 설명, 가맹 제안서 초안.
- 장애인 탭.

### P2

- 지자체 공지 모니터링(휴관·가맹 모집) → 시설 상태 변경 후보.
- 기존 시설 하나를 제외하는 스트레스 테스트.

### 제외

가맹 신청 대행, 자동 연락·메일, 실시간 잔여석, 예산 집행, 주민 개인 계정, 수요 자동 추정(잠재 수요를 이력에서 복원하지 않음), 건강 효과 예측, 챗봇 상담.

## 8. 검증 계획

| 대상 | 과제 | 지표 |
|---|---|---|
| 담당자 3~5명 | 같은 지역의 유치 후보 10곳 + 협의 계획 1건을 수작업 vs 시제품으로 작성 | 작성 시간, 접촉 가치 있다고 본 후보 비율, 누락한 결합 조치 수 |
| 시설 운영자 3~5명 | 동네 브리프·가맹 제안서 열람 | 가맹 의향, 몰랐던 정보, 문서 수정 요구 |
| LLM 추출 | 수동 라벨 50건 | 필드별 정확도, 신뢰도 보정, 검토 큐 반려율 |
| LLM 매칭 판정 | 수동 라벨 50쌍 | 정밀도·재현율, "불명" 비율 |
| 문서 초안 | 20건 | 근거 없는 숫자 0건(코드 검증), 담당자 수정량 |
| 엔진 | 합성 시나리오 + 탐욕 비교 | 조합 누락 재현, 제약 위반 0 |

표본이 작으므로 일반화하지 않고, 의향을 성과로 보고하지 않습니다.
