## 검증하지 못한 것 / 가정

- LLM은 2026-09-18 Claude에서 OpenAI Responses API(`gpt-5.6-luna`)로 교체했고 실제 호출을 확인했습니다. 다만 추출 정확도 평가 세트(라벨 50건)는 아직 만들지 않아 정확도 수치는 없습니다. 코드는 SDK 문서 기준으로 작성했고 오프라인 테스트만 통과.
- 브라우저 실화면 확인(레이아웃·모바일 실기기)은 자동화 도구 없이 진행. HTML 렌더링·JS 문법은 검사했으나 런타임 UI 동작은 사용자 확인 필요.
- 수강료는 이용현황의 월별 금액을 월 수강료로 해석(원본에 단위 없음). 신청 인원은 월별 신청 수의 합.
- 강좌 시간표는 (종목·강좌명·가격·연도)로 결합. 같은 이름의 시간표가 여럿인 강좌 30,491개는 "모호"로 표시하고 최신 연도를 택함.
- 인천 신설구(제물포·영종·검단·서해)는 옛 중구·서구로 근사.
- 개방학교 데이터는 2017~2025 기준연도 혼재.
