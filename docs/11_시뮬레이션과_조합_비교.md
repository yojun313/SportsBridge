# 시뮬레이션과 조합 비교

기준: 2026-10-30 현재 코드. 가맹 협의·강좌 신설·정원 추가·이동 지원을 조합해, **입력한 예산과 조건에서 몇 명을 강좌에 배정할 수 있는지** 계산하는 기능입니다. AI가 인원이나 비용을 추정하는 계산은 아닙니다.

## 입력과 사용하는 자료

입력은 지역, 수요 집단, 대상 강좌, 개선 조치, 예산입니다. 집단은 최대 10개, 강좌는 30개, 조치는 10개입니다. `/scenario`에서 작성하고 `/scenario/compare`에서 비교합니다.

공개 가맹시설·이용현황·강좌표에서 시설·종목·월 수강료·시간표를 초기값으로 가져옵니다. 검토된 추출 정보가 있으면 연령·출석 규칙도 참고합니다. 전체 시설의 가맹 검토 후보와 서비스의 희망 등록도 초기값에 사용합니다.

하지만 **실제 추가 수용 인원과 조치 비용은 공공자료에 없어 직접 입력**합니다. 등록 건수를 실제 인원으로 확정하지 않고, 확인값과 시험용 가정값을 구분합니다. API 계산 시에는 이 입력 묶음 자체를 사용하며 최신 DB의 정원·비용으로 자동 보완하지 않습니다.

## 1. 선택한 조치를 가상으로 적용합니다

| 조치 | 계산에서 바꾸는 상태 |
|---|---|
| 가맹 협의 | 해당 시설을 스포츠 강좌이용권 가맹 상태로 가정 |
| 강좌 신설 | 선택한 예정 강좌를 개설 상태로 바꾸고 입력한 자리 수를 추가 |
| 정원 추가 | 해당 강좌의 추가 수용 인원에 자리 수를 더함 |
| 이동 지원 | 지정한 집단이 지정한 시설로 이동할 수 있는 상태로 가정 |

이 작업은 실제 가맹·개설·이동 지원을 실행하지 않습니다. 신설 조치의 정원도 강좌 입력 정원에 **더하므로**, 새 강좌 8자리를 시험한다면 강좌 기본 정원 0과 신설 조치 정원 8처럼 중복되지 않게 입력합니다.

## 2. 집단과 강좌가 연결될 수 있는지 확인합니다

각 집단과 각 강좌를 짝지어 아래 조건을 검사합니다. 하나라도 맞지 않으면 그 연결을 제외하고 이유를 남깁니다.

| 조건 | 판정 방법 |
|---|---|
| 종목 | 집단의 희망 종목과 강좌 종목이 같아야 함 |
| 연령 | 양쪽에 범위가 있으면 집단 전체 범위가 강좌 범위 안에 있어야 함. 한쪽 연령이 전혀 없으면 이 조건으로 차단하지 않음 |
| 요일·시간 | 수업 전후의 이동·준비 여유까지 집단의 이용 가능 시간 안에 있어야 함 |
| 출석 규칙 | 전 요일 필수·미확인은 모든 수업이 맞아야 함. 요일 선택은 맞는 수업 횟수가 주당 필요 횟수 이상이어야 함(미입력 시 1회) |
| 이동 | 이동 가능이 확인됐거나 해당 집단·시설의 이동 지원 조치가 있으면 통과. 이동 불가는 차단. 미확인일 때 자력 이동·기관 차량은 통과하지만 이동 지원 필요 집단은 차단 |
| 가맹 | 가맹으로 입력됐거나 해당 시설의 가맹 협의 조치가 선택되어야 함 |
| 개설 | 기존 강좌이거나 해당 강좌의 신설 조치가 선택되어야 함 |
| 정원 | 정원·비용 방식에서 미확인 정원은 배정 대상에서 제외. 0명은 연결 조건이 맞아도 배정할 자리가 없음 |

강좌 시간표가 없으면 연결하지 못합니다. 반대로 집단의 이용 가능 시간을 모두 비우면 시간 제약 없이 비교합니다. 빈칸을 모든 항목에서 같은 뜻으로 해석하는 방식은 아닙니다.

## 3. 가능한 자리로 최대한 많은 인원을 배정합니다

정원·비용 방식은 ‘최대유량’ 계산을 사용합니다. 쉽게 말하면 **각 집단의 인원을, 조건이 맞는 강좌의 남은 자리로 보내면서 전체 배정 수를 최대화**합니다.

집단 8명이 있고 맞는 강좌의 자리가 각각 3석·5석이면 두 강좌로 나눠 8명을 배정할 수 있습니다. 한 사람을 여러 자리에 중복 배정하지 않지만 집단 전체가 반드시 같은 강좌에 들어가야 하는 것은 아닙니다. 공평한 집단별 배분이나 선호도 순서까지 별도로 최적화하지는 않습니다.

**정원 미적용 비교**는 개설된 강좌의 정원을 사실상 제한 없이 두고, 연결 가능한 강좌가 하나 이상인 **집단 수**를 셉니다. 정원 입력이 0이어도 다른 조건이 맞으면 연결됩니다. 결과를 사람 수나 실제 잔여석으로 읽으면 안 됩니다.

## 4. 조치 조합을 모두 비교합니다

1. 조치가 없는 현재 상태부터 시작해, 최대 10개 조치의 모든 조합을 만듭니다. 가능한 조합 수는 최대 `2¹⁰ = 1,024`개입니다.
2. 필요한 선행 조치가 빠졌거나 동시에 선택할 수 없는 조치가 함께 있으면 해당 조합을 제외합니다.
3. 나머지 조합마다 상태 적용·조건 확인·배정을 반복하고 조치 비용을 합산합니다. 월 수강료는 이 조치 예산에서 차감하지 않습니다.
4. 예산 초과 또는 비용 미확인 조합은 **예산 내 최선 조합에서 제외**합니다. 예산을 비우면 상한이 없고, 예산 0이면 비용 0인 조합만 최선 후보가 됩니다. 비용 미확인은 예산을 비워도 최선 후보에서 빠집니다.
5. 배정 인원(정원 미적용 비교는 연결 집단 수)이 가장 많은 조합을 고릅니다. 같으면 비용이 적은 조합, 조치 수가 적은 조합, 조치 ID 순서로 정합니다.

화면의 상위 조합은 최대 12개이며 예산 초과·비용 미확인 조합도 검토용으로 포함될 수 있습니다. ‘평가한 조합’ 건수는 선행·동시 선택 불가 조건을 통과한 수로, 최대 1,024개와 다를 수 있습니다.

## 개별 선택과 결합 효과를 함께 보는 이유

‘개별 효과 순 선택 결과’는 매 단계에서 **현재 조합에 하나를 더했을 때 가장 많이 증가하는 조치**를 고르는 방식입니다. 증가가 없는 조치는 추가하지 않으므로, 두 조치를 함께 해야만 효과가 생기는 경우를 놓칠 수 있습니다. 처음의 단독 효과 순서를 고정해 사용하는 계산은 아닙니다.

가정 예시: 수영 희망 집단 8명, 기존 추가 자리 0, 미가맹·신설 예정 강좌의 기본 정원 0을 입력합니다. 시간·연령·이동은 맞는 조건으로 두고 가맹 협의 20만 원, 강좌 신설 8자리·60만 원을 설정합니다. 신설에는 가맹 협의를 선행 조건으로 지정하고 예산은 90만 원으로 둡니다.

- 현재 상태: 자리와 개설 조건이 없어 **0명**.
- 가맹 협의만: 강좌가 개설되지 않아 **0명**. 신설만은 선행 조건을 어겨 조합에서 제외.
- 둘을 함께 선택: 총 **80만 원으로 8명** 배정. 전체 조합 비교는 이 조합을 찾습니다.
- 개별 선택 방식: 가맹 협의 하나의 증가가 0이므로 시작하지 못해 **0명**. 결합 효과 설명에서 이 차이를 확인합니다.

이는 계산 원리를 보여주는 가정이며 실제 시설의 정원·협의 비용이나 정책 효과를 뜻하지 않습니다.

## 결과와 주의점

결과에는 현재 상태, 최선 조합, 개별 선택 결과, 단독 효과, 상위 조합, 집단별 배정과 이용 불가 사유가 포함됩니다. 조건상 연결 가능해도 자리 0·경쟁 집단의 배정 때문에 해당 집단의 배정은 0명일 수 있습니다.

직접 조합을 평가하는 `POST /api/scenarios/evaluate`는 입력한 선택 조치를 계산하지만 **선행·동시 선택 불가 조건을 다시 검사하지 않습니다**. 이 조건을 확인하는 전체 비교 경로와 범위가 다르므로 임의 조합·계획서를 볼 때는 별도로 확인해야 합니다. 표시되는 가정값 사용 항목도 선택 조치와 입력 정원 중심이므로 모든 불확실성을 보증하는 목록은 아닙니다.
