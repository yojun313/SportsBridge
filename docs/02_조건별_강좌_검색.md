# 조건별 강좌 검색과 조건 변경 제안

기준: 2026-10-30 코드 · 화면: `/user` · 요청: `POST /api/user/recommend`

지역의 강좌를 하나씩 살펴보고, 입력한 조건과 맞는지 분류하는 기능입니다. 실제 수강 신청·예약이나 잔여석 조회는 하지 않습니다.

## 입력과 사용하는 데이터

입력은 시군구, 최대 3개 희망 종목, 만 나이, 이용 가능한 요일·시간, 이동·준비 여유, 월 수강료 예산입니다. 화면에서 선택한 요일에는 같은 시작·종료 시각을 적용합니다.

| 데이터 | 이 기능에서 사용하는 정보 |
|---|---|
| 스포츠 강좌이용권 이용현황 | 강좌번호·이름·종목·시설·월별 신청 인원·금액·마지막 기록월 |
| 스포츠 강좌이용권 이용시설 강좌 | 강좌명·종목에 연결한 요일·시작·종료 시각·강좌 설명 |
| 스포츠 강좌이용권 시설 | 시설명·주소·전화와 연결된 가맹시설 정보 |
| 스포츠 강좌이용권시설 인접 대중교통 | 시설에 연결된 정류장과 최소 도보시간 |
| 전국체육시설현황·체육시설 안전점검정보 | 동일 시설로 연결된 경우의 안전점검 결과 등 보충 정보 |
| 개방학교 체육시설 | 별도 결과 영역에 표시할 학교 개방시간·종목·편의시설 |
| 담당자가 검토한 AI 추출 정보 | 공개 강좌 설명에서 추출한 대상 연령·출석 규칙 |

원본 CSV를 매 검색마다 읽지는 않습니다. 사전에 가공해 저장한 현재 사용 버전의 데이터를 조회합니다. 공통 파싱·연결 과정은 [데이터셋과 공통 가공](01_데이터셋과_공통_가공.md)을 참고합니다.

## 처리 흐름: 다섯 단계

1. **검색할 강좌를 모읍니다.** 선택한 시군구에서 마지막 기록월이 집계 시작월 이후인 강좌를 불러옵니다. 시설·교통·안전·추출 정보를 강좌에 붙입니다.
2. **시간을 숫자로 바꿉니다.** 화면의 `16:00`은 하루 시작 후 960분으로 전달합니다. 수업 요일과 시간이 이용 가능 구간에 완전히 들어가는지 비교합니다.
3. **각 강좌의 조건을 검사합니다.** 아래 기준으로 불일치 사유와 확인할 항목을 따로 모읍니다.
4. **결과를 분류하고 정렬합니다.** 세 분류의 전체 건수와 일부 강좌 목록을 반환합니다.
5. **조건을 바꿔 다시 계산합니다.** 결과가 늘어나는 변경안과 개방학교·가맹 검토 시설을 함께 보여줍니다.

## 어떤 기준으로 맞는지 판단하나

| 조건 | 검사 방식 |
|---|---|
| 종목 | 종목을 선택했다면 해당 종목에 포함되어야 합니다. 미선택은 전체 종목입니다. |
| 시간 | 수업 전후에 이동·준비 여유를 각각 더해도 같은 요일의 이용 가능 구간 안에 들어가야 합니다. |
| 출석 규칙 | 전 요일 필수는 모든 수업이 맞아야 합니다. 요일 선택은 필요한 주당 횟수만큼 맞으면 되며, 횟수 미입력은 1회입니다. 현재 검색 화면에는 주당 횟수 입력란이 없습니다. |
| 규칙 미확인 | 일단 모든 수업 참여를 기준으로 비교합니다. 일부 시간만 맞으면 ‘확인 필요’, 맞는 시간이 하나도 없으면 ‘조건 불일치’입니다. |
| 연령 | 나이를 입력했다면 검토 완료된 강좌 대상 연령과 비교합니다. 강좌 연령이 없으면 ‘확인 필요’입니다. 나이를 비우면 비교하지 않습니다. |
| 월 예산 | 지원금 차감 전 월 수강료와 비교합니다. 예산 초과는 불일치, 수강료 미확인은 확인 필요입니다. |
| 자료 상태 | 시간표 연결 후보가 여러 개이거나 마지막 집계월 신청 인원이 0명·미확인이면 확인할 항목을 추가합니다. 시간표 자체가 없으면 연결 불가 사유가 됩니다. |

연령·출석 규칙은 **담당자 검토 완료(`llm_reviewed`) 정보만** 판정에 사용합니다. 미검토 AI 추출값이 화면에 보이더라도 확인된 조건으로 적용하지 않습니다.

요일을 전부 해제하면 시간 제한 없이 비교하지만, 시간표 자체가 없는 강좌는 통과하지 못합니다. 이용 유형은 지원 자격을 판정하지 않으며, 이동 수단도 실제 검색 제외 조건으로 사용하지 않습니다. 도보시간은 보충 정보와 정렬에만 사용하고 출발지부터의 경로를 계산하지 않습니다.

## 결과 분류와 표시 순서

- **조건 불일치**: 종목·시간·연령·예산 등에 불일치 사유가 하나라도 있습니다.
- **확인 필요**: 불일치 사유는 없지만 출석 규칙·연령·가격 등 확인할 항목이 있습니다.
- **조건 일치**: 불일치 사유와 확인할 항목이 모두 없습니다.

표시 순서는 조건 일치 → 확인 필요 → 조건 불일치입니다. 같은 분류에서는 확인 항목이 적은 순, 선택한 종목 우선순위, 수강료, 정류장 도보시간, 마지막 집계월 신청 인원 등을 차례로 비교합니다.

전체 건수는 해당 지역의 검사한 강좌 전체를 셉니다. API는 분류마다 최대 30개를 돌려주고, 화면의 조건 불일치 목록은 최대 20개만 표시합니다.

## 조건 변경 제안은 어떻게 만드나

현재 결과 중 **조건 일치 + 확인 필요 강좌 수**를 기준으로, 아래 변경안을 각각 독립적으로 적용해 다시 셉니다.

- 토요일·일요일 09~18시 추가, 이용 가능 시간 앞뒤 1시간 확장, 평일 저녁 18~21시 추가
- 월 예산 1만·3만·5만 원 상향, 이동·준비 여유를 0분으로 변경
- 현재 고르지 않은 종목 중 지역 강좌 수가 많은 최대 3개 종목을 하나씩 추가

강좌 수가 늘어난 제안만 증가량이 큰 순서로 최대 6개 표시합니다. 제안의 `+숫자`는 늘어난 강좌 수이며 인원·정원·효과 예측값이 아닙니다. 제안을 누르면 그 조건으로 다시 검색합니다.

## 작은 예시와 연결 기능

이용 가능 시간이 월요일 15:45~17:15이고 이동·준비 여유가 15분이면, 월요일 16:00~17:00 수업은 시간 조건을 만족합니다. 연령·종목·예산도 맞고 확인 항목이 없어야 최종 ‘조건 일치’가 됩니다.

검색 결과에는 개방시간이 일부라도 겹치는 학교 체육시설 최대 20곳과 같은 지역의 가맹 검토 후보도 붙습니다. 이것이 무료 이용·현재 개방·실제 미가맹이나 가까운 거리순을 보장하지는 않습니다. `☆ 저장`은 강좌 정보를 현재 브라우저의 관심 목록에 저장하며, 검색만으로 희망 등록이나 실제 수강 신청을 실행하지 않습니다.
