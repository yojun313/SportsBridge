# 스포츠브릿지 기능별 로직 안내

기준일: 2026-10-30. 현재 코드를 기준으로 각 기능이 어떤 데이터를 읽고, 어떻게 가공해 결과를 만드는지 설명합니다. 각 문서는 실제 코드와 연결되어 있습니다. 코드 링크는 현재 작업공간의 파일과 해당 줄을 가리키며, 줄 번호는 이 기준일의 코드 기준입니다.

## 전체 흐름

`공개 CSV 10종 → 형식 정리·지역/시설/강좌 연결 → 버전 식별값을 붙여 MongoDB에 저장 → 검색·통계·후보 점수·지원 방안 계산 → 화면·CSV·계획서`

이용자가 등록한 희망 조건과 시설 이용 의견은 공개 데이터와 별도로 저장합니다. AI는 설명 추출·자료 조회·문장 작성을 보조하며, 시설 수나 지원 방안의 배정 인원을 임의로 만드는 역할은 아닙니다.

## 먼저 구분할 데이터

- **수강 신청 누계**: 공개 이용현황의 월별·강좌별 신청 인원 합계입니다. 같은 사람이 반복 포함될 수 있습니다.
- **희망 등록 건수**: 이 서비스에 등록한 의견입니다. 지역 전체 수요나 실제 수강 신청 인원은 아닙니다.
- **집계기간 내 기록 있음**: 자료에 강좌 기록이 있는 상태입니다. 현재 영업·모집 여부를 보장하지 않습니다.
- **시뮬레이션 결과**: 입력한 정원·시간·비용·가맹 조건에서 계산한 가능 인원입니다. 실제 참여·가맹 승인·예산 집행 결과가 아닙니다.

원본의 기준일·집계기간·미확인 정보에 따라 결과 해석이 달라집니다. 각 기능 문서의 ‘주의할 점’도 함께 확인해 주세요.
