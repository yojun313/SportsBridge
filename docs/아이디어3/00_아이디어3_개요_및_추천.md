# 아이디어3 — 개요와 추천

작성일: 2026-09-18 / 작성: Claude / 상태: 웹 조사 기반 후보안 (원본 CSV 미검증)

## 0. 이 폴더가 아이디어1·2와 다른 점

아이디어1(우리 아이 운동시간표)은 **보호자가 강좌를 찾는 수요자용 검색·추천**이었고, 공식 스포츠강좌이용권 사이트·학원 앱·운동 앱과 겹쳐서 폐기 검토 중입니다. 아이디어2는 Codex가 작성 중 중단되었고, 사용자 지시에 따라 그 방향(시설 휴관 대응 시뮬레이션)은 참고하지 않았습니다.

아이디어3은 **시점을 수요자에서 공급자로 옮깁니다.** 조사 결과, 스포츠강좌이용권의 실제 병목은 "강좌를 못 찾는 것"이 아니라 **"이용권을 받아도 동네에 쓸 곳이 없는 것"**입니다. 이 문제를 다루는 도구는 공공·민간 어디에도 확인되지 않았습니다. 기존 서비스(공식 사이트, 체육시설알리미, 학원 앱, 상권분석)는 전부 **이미 가맹된 시설을 이용자에게 보여주는** 방향이고, **어느 지역에 어떤 시설을 새로 가맹시켜야 하는지**를 계산해 주는 도구는 없습니다.

## 3. 대회 요건과의 연결

- 공단 데이터 1건 이상 필수 → A는 공단 데이터만으로 핵심 기능이 동작하고, 융복합 상품(26, 08, 06, 07, 29)을 적극 활용합니다.
- 서비스 개발 부문(시제품 필수, 10/2 마감) → 로그인 없이 지역을 고르면 진단→후보 목록→내보내기까지 되는 웹 한 벌이면 충분합니다.
- 공단 사업(이용권)의 **이용률 개선**에 직접 닿는 주제라 심사 취지와 맞습니다. 다만 심사 배점은 미확인이므로 유불리를 단정하지 않습니다.

## 5. 정직하게 남기는 한계

- "기존 서비스가 전혀 없다"는 것은 웹 검색으로 증명할 수 없습니다. 공단 내부 관리 도구에 유사 기능이 있을 수 있습니다. 문서에는 검색어와 확인한 사이트를 남기고, 제출 시 "공개된 서비스 중 미발견"으로 표현합니다.
- 상품 설명만 확인했고 원본 컬럼·행 수·결측·기준일은 미검증입니다. 특히 64 전국체육시설현황과 80 가맹시설의 매칭 가능성이 A의 성패를 좌우합니다.
- 시설 수·강좌 수는 수용 인원이 아닙니다. 대상자 대비 시설 수 비율을 "공급 충분/부족"으로 단정하지 않고 "상대 순위"로만 표시합니다.
