- 사용할 기능: 시간대·종목·예산 필터, 추천 강좌 비교, 주간 시간표.
- 원본에서 반드시 확인할 항목: **시설 데이터와 연결할 식별자**, 강좌 고유번호, 대상 연령·학년 유무, 금액의 단위와 과금 기간, 강좌 운영기간, 수강 가능 상태.

- 주의: 여러 요일이 적혀 있다고 해서 사용자가 그중 원하는 날만 선택해 수강할 수 있다는 뜻은 아닙니다. 필수 출석 요일인지 선택 가능한 요일인지 확인이 필요합니다.
- 주의: 수강료가 월 단위인지 확인하기 전에는 월 예산과 직접 비교하지 않습니다. 현재 정원·잔여석·즉시 예약 가능 여부는 공개 설명에서 확인되지 않았습니다.

## 다운로드·전달 방법

1. 상품 페이지에 접속하고 필요한 경우 플랫폼 회원가입·로그인을 진행합니다.
2. 최신 기준의 CSV를 다운로드합니다. 가능하면 **전국 원본**을 받아주세요. 시범 지역은 데이터 품질을 확인한 뒤 정합니다.
3. 각 상품의 **컬럼 정의서**도 함께 다운로드합니다. 정의서가 화면으로만 보인다면 파일로 저장하거나 컬럼명·설명을 전달해주세요.
4. 파일명과 원본 내용을 수정하지 말고 아래 경로에 넣어주세요. ZIP으로 제공되면 ZIP 원본도 보관합니다.
5. 이용허락·상업적 이용·재배포 조건이 표시된다면 해당 안내나 문서도 함께 보관해주세요. 무료라는 표시와 재배포 허용은 별개의 문제입니다.

권장 경로:

```text
/home/yojun/sports/data/raw/
  facilities/       # 1번 원본·정의서
  courses/          # 2번 원본·정의서
  regional_usage/   # 3번 원본·정의서
```

위 경로는 권장 배치이며 아직 디렉터리나 데이터가 있다는 뜻은 아닙니다. 파일을 다른 곳에 저장했다면 절대경로만 알려줘도 됩니다.

엑셀로 열어 다시 저장하면 선행 0, 전화번호, 시간, 긴 식별자가 변형될 수 있으므로 **다운로드한 원본 그대로** 전달하는 것이 좋습니다. 계정 비밀번호나 로그인 쿠키는 전달하지 마세요.

## 파일을 받은 뒤 개발 전에 확인할 사항

- 시설·강좌를 공통 ID로 연결할 수 있는지와 실제 연결 성공률.
- 지역별 시설 수·강좌 수, 중복과 누락.
- 요일·시작시간·종료시간이 채워진 강좌의 비율.
- 수강료 단위, 필수 요일·선택 요일의 의미, 대상 연령 정보.
- 파일 내부 기준일, 실제 운영 여부를 확인할 수 있는 정보.
- 공통 ID가 없으면 시설명+주소 정규화로 매칭하고, 불확실한 매칭은 추천 대상에서 제외.

결과가 좋으면 시간표 추천을 진행합니다. 시간 정보가 부족하면 확인된 강좌만 사용하거나 시설 탐색·문의 보조로 기능을 축소합니다. 데이터가 없는 값을 AI로 채워 넣어 실제 정보처럼 표시하지 않습니다.
