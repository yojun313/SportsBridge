# 우리 아이 운동시간표 — 서비스 기획서

작성일: 2026-09-18 / 버전: 0.1 / 상태: 차별화·데이터 검증 전 초안

## 1. 기획 전제

기존 시설 검색·학원 시간표·운동 추천 서비스가 확인되었습니다. 이 문서는 ‘유사 서비스 없음’이라는 조건이 충족된 최종안이 아닙니다. [시장조사](02_대회_시장조사_아이디어.md)의 중복과 한계를 전제로, 개발할 경우의 구체적인 범위를 정리합니다.

목표: **가족의 생활 조건에서 다닐 수 있는 스포츠강좌이용권 수업을 찾고, 비교하고, 주간 계획에 담는 시간을 줄인다.**

가칭은 ‘우리 아이 운동시간표’, 코드명은 `sports`. AI 사용은 필수가 아닙니다. 실제 데이터에 근거한 제약 검사와 설명이 제품의 핵심입니다.

## 2. 이용자와 해결할 문제

1차 이용자: 이용권 사용을 준비하거나 사용 중인 초등학생 보호자. 학교명·아이 실명·정확한 집 주소·수급 유형을 수집하지 않는 흐름으로 시작합니다.

2차 이용자: 보호자의 강좌 탐색을 돕는 지역아동센터 담당자. 여러 아동의 민감정보를 한 계정에 관리하는 기능은 초기 범위 밖입니다.

가설:

- 시설마다 시간을 확인하는 과정이 번거롭다.
- 가까워도 기존 일정과 맞지 않거나 준비·이동시간이 부족하다.
- 조건에 맞는 수업이 없으면 무엇을 바꿔 검색해야 할지 모르겠다.

이 가설들은 인터뷰로 검증해야 하며, 현재 확인된 사용자 조사 결과가 아닙니다. 수요 배경과 출처는 시장조사 문서에 있습니다.

## 3. 제안하는 차별화

| 기능 | 사용자 가치 | 사실을 판정하는 기준 |
|---|---|---|
| 가능 시간에 강좌를 대입 | 수업 시간을 일일이 비교하는 수고 감소 | 강좌 전체 시간 구간의 포함 여부 |
| 이동·준비 여유 반영 | 시작 직전까지 다른 일정이 있는 후보 구분 | 사용자가 입력한 편도 이동·준비 분량 |
| 예산 조건 검사 | 공시 수강료를 기준으로 후보 비교 | 가격 단위가 검증된 강좌만 비교 |
| 조건 변경 제안 | 결과 0건에서 다음 행동 제시 | 한 조건씩 바꿔 실제 검색 결과 재계산 |
| 데이터 확인 상태 표시 | 최신 여부·누락을 알고 문의할 수 있음 | 원본 기준일과 별도 확인일 구분 |

거리 자동 계산은 좌표 확보 후 확장합니다. 최초 시제품의 이동시간은 사용자가 정하는 여유시간이며 실제 길찾기 결과로 표현하지 않습니다.

## 4. 핵심 사용자 여정

```text
지역·종목·예산 입력
    ↓
주간 가능 시간 선택 + 편도 이동·준비 여유 입력
    ↓
조건에 맞는 강좌 / 확인이 필요한 강좌 분리
    ↓
최대 3개 비교 → 한 강좌를 주간 계획에 담기
    ↓
시설 문의 또는 공식 사이트에서 최종 확인·신청
```

결과가 없으면 ‘토요일도 선택’, ‘예산 상향’ 등 실제로 후보를 늘리는 변경만 제안합니다. 원래 조건은 사용자가 적용하기 전까지 유지합니다.

## 5. 입력과 추천 결과

### 필수 입력

- 시도·시군구: 데이터가 있는 지역 목록에서 선택.
- 선호 종목: 최대 3개. 복수 선택은 OR 조건.
- 요일별 가능 시간: 주간 반복, 15분 UI 단위, 한국 시간.
- 이동·준비 여유: 편도 분량, 기본 0분을 명시적으로 표시하고 수정 가능.
- 예산: 선택 입력. 단위 확인된 월 수강료를 기준으로 월 최대 금액 입력.

### 선택 입력

- 아이 연령: 대상 연령이 검증된 강좌에만 적합성 검사. 모르는 강좌를 임의로 적합 판정하지 않음.
- 원하는 주당 횟수: 강좌 출석 규칙을 확인한 뒤 기능 활성화.

### 결과 카드

강좌명, 시설, 종목, 요일·시간, 공시 수강료와 단위, 지역·주소, 추천 이유, 확인 필요 항목, 데이터 기준일, ‘비교’, ‘시간표 담기’, ‘문의하기’를 표시합니다.

결과 상태는 ‘조건 일치’, ‘확인 필요’, ‘조건 불일치’로 구분합니다. 조건 일치도 현재 모집 중·신청 가능·이용권 지원 확정을 뜻하지 않습니다. 상태 문구는 ‘시간 조건 일치 · 운영 여부 확인 필요’처럼 해당 범위를 구체적으로 씁니다.

‘추천 98%’, ‘만족도 99%’, ‘가장 안전한 강좌’ 등 검증되지 않은 수치는 쓰지 않습니다.

## 6. 화면 정의

| 화면 | 경로 | 주요 구성 |
|---|---|---|
| 소개 | `/` | 서비스 설명, 조건 입력 시작, 데이터 기준 안내 |
| 조건 입력·추천 | `/planner` | 조건 패널, 주간 가능 시간 그리드, 결과 목록 |
| 강좌 상세 | `/courses/{id}` | 요일·시간·가격·시설·출처·확인 필요 사항 |
| 비교 | `/compare` | 최대 3개 강좌의 시간·비용·상태 비교 |
| 내 운동 계획 | `/plan` | 기기 내 저장한 주간 계획, 삭제·인쇄 |
| 데이터 안내 | `/data` | 출처·기준일·지원 지역·알려진 한계 |

PC는 입력 패널과 결과 영역을 나누고, 모바일은 ‘조건→시간→결과’ 순서로 표시합니다. 7일 시간표를 모바일에 억지로 축소하지 말고 요일 전환 또는 스크롤을 제공합니다. 드래그 이외에 시작·종료 시각을 직접 입력하는 대체 UI를 제공합니다.

## 7. 시간·요일 규칙

- 계산 기준은 `Asia/Seoul`, 요일 월=0~일=6, 시각은 자정 이후 분 단위.
- 수업이 16:00~17:00이고 이동·준비가 편도 15분이면 15:45~17:15가 가능 시간 안에 들어와야 합니다.
- ‘월·수·금’이 필수 출석 패키지이면 세 요일을 모두 검사합니다.
- 선택 가능한 요일이라는 근거가 있으면 선택 수강 조합을 만들 수 있습니다.
- 요일의 의미가 불명확하면 ‘확인 필요’로 분류하고 주간 출석 횟수를 확정하지 않습니다.
- 시간 누락·잘못된 요일·자정 넘김 등 해석이 확정되지 않은 행은 자동 시간표에 넣지 않습니다.
- 여러 강좌를 담으면 수업뿐 아니라 이동·준비를 포함한 구간도 충돌 검사합니다.
- 인접한 두 수업 사이를 바로 이동하는 최적 경로는 초기 범위에서 제외합니다. 각 강좌 앞뒤의 여유를 보수적으로 확보합니다.

## 8. 가격과 지원금 규칙

초기에는 **공시 수강료와 사용자가 정한 예산**을 비교합니다. 원본에 월·회·기간 단위가 명확하지 않으면 가격 필터의 적합 후보에서 제외하고 확인 필요로 표시합니다.

2026년 지원 제도 안내는 [공식 사이트](https://svoucher.kspo.or.kr/main.do)에서 확인하도록 연결합니다. 개인별 지원 자격·잔액·복수 강좌 사용·본인부담 가능 여부가 확인되지 않았으므로 ‘무료’, ‘지원 확정’, ‘본인 부담 0원’을 자동 계산하지 않습니다. 지원금 계산은 제도와 데이터 검증 후 확장합니다.

## 9. 시제품 우선순위

### P0: 제출 가능한 최소 기능

- 실제 CSV의 검증·정규화·검색.
- 시설·강좌 연결과 데이터 출처 표시.
- 지역·종목·가능 시간·이동 여유·검증된 가격 필터.
- 결과 0건일 때 한 조건 변경에 따른 후보 수 제시.
- 강좌 비교와 기기 내 주간 계획 저장·삭제·인쇄.
- 전화번호와 공식 사이트 연결.
- 밝은/어두운 테마, 모바일·키보드 입력 지원.

### P1: 핵심 완료 후

- 좌표 기반 직선거리 필터 또는 지도 표시. 직선거리를 실제 이동시간으로 바꾸어 표시하지 않음.
- 지역별 통계 설명 화면.
- 명시적 선택을 거친 기기 간 계획 저장.

### 초기 범위 제외

직접 수강신청·결제, 잔여석 확인, 지원금 잔액 연동, 출석 연동, 셔틀 최적화, 여러 자녀 동시 배정, 운동처방, 커뮤니티, AI 챗봇, 외부 알림 자동 발송.

## 10. 데이터 품질에 따른 범위 결정

첫 데이터 검사에서 지역별 연결 성공률, 시간 파싱 가능률, 가격 단위 확인률을 보고합니다. 숫자를 미리 채우지 않습니다.

시범 범위 목표는 한 시군구와 데이터가 충실한 2~3개 종목입니다. 표본 점검 목표는 실제 강좌 30개 정도이며, 확보하지 못하면 검증한 실제 건수를 공개합니다. 결측 강좌를 가상 수업으로 보충하지 않습니다.

- 시간·출석 규칙이 확인된 강좌가 충분하면 본 기획 진행.
- 일부만 확인되면 확인된 하위 집합으로 시범 범위 축소.
- 핵심 정보가 거의 없으면 자동 시간표 개발을 중단하고 시설 탐색·문의 보조 또는 다른 아이디어를 재검토.

## 11. 사용자 검증 계획

대상 목표: 보호자 또는 지역아동센터 담당자 5~10명. 모집·연락은 사용자가 진행하며, 현재 모집되었다는 의미가 아닙니다.

과제: 동일한 가상 가족 조건으로 기존 공식 사이트와 시제품에서 적합한 강좌를 찾습니다. 순서를 교차 배정해 학습 효과를 줄이고, 강좌 운영 사실은 별도 확인합니다.

측정: 적합 후보 발견까지 걸린 시간, 실제 조건 위반 후보 수, 찾지 못한 비율, 문의 버튼 이용, 사용자가 이해한 확인 필요 항목. 목표 예시는 탐색 시간 중앙값 30% 감소이며 **성과가 아닌 검증 목표**입니다.

샘플이 작으므로 전체 이용자의 개선 효과로 일반화하지 않습니다. 문의 의향·클릭을 실제 수강·출석 성과로 바꾸어 보고하지 않습니다.

## 12. 운영과 확장 가설

초기 사용은 무료로 가정합니다. 기관용 탐색 보조·지역별 공급 분석 도입은 장기 가설이며, 구매 의향이나 사업성을 검증한 상태가 아닙니다. 시제품 단계에서 광고 수수료로 추천 순위를 바꾸지 않습니다.

데이터 갱신 시 기존 저장 강좌의 버전 차이를 감지해 재확인을 요청합니다. 기기 내 계획 초기화 버튼과 공개 데이터의 오류 안내를 제공합니다. 입력한 상세 일정·주소를 로그에 남기지 않습니다.
