# 시설 검색과 상세 조회

기준: 2026-10-30 코드 · 화면: `/user/facilities`

스포츠 강좌이용권 관련 공개 자료에 포함된 시설을 검색하고, 시설별 강좌·시간표·수강료·최근 기록을 확인하는 기능입니다.

## 사용하는 데이터

| 데이터 | 활용하는 정보 |
|---|---|
| 스포츠 강좌이용권 시설 | 시설명·주소·상세 주소·전화·운동 종목·가맹 정보 |
| 스포츠 강좌이용권 이용현황 | 시설에 연결할 강좌, 마지막 기록월, 월별 신청 인원과 금액 |
| 스포츠 강좌이용권 이용시설 강좌 | 강좌에 연결할 요일·시작·종료 시각 |
| 스포츠 강좌이용권시설 인접 대중교통 | 시설과 연결된 정류장·최소 도보시간 |

사전 가공에서 지역·시설명·주소를 정리해 같은 시설을 연결합니다. 이용현황의 강좌번호로 월별 기록을 묶고, 별도 강좌 자료의 시간표를 연결합니다. 검색할 때는 이 가공 결과가 저장된 현재 사용 버전을 조회합니다.

## 목록이 만들어지는 순서

1. **지역을 고릅니다.** 시군구 코드가 같은 가맹시설 자료를 찾습니다.
2. **종목과 이름을 적용합니다.** 종목은 시설에 기록된 종목 목록으로 찾고, 시설명은 입력 글자가 포함된 항목을 찾습니다. 이름의 특수문자는 검색 명령으로 해석하지 않고 일반 글자로 처리합니다.
3. **강좌 기록을 확인합니다.** ‘집계기간 내 강좌 기록 있는 곳만’을 선택하면 마지막 기록월이 집계 시작월 이후인 시설만 남깁니다. 기본값은 선택 상태입니다.
4. **시설별 강좌를 셉니다.** 집계기간의 강좌를 모아 전체·저녁·주말 강좌 수, 강좌가 있는 종목, 확인된 월 수강료 중 최저값을 계산합니다.
5. **저녁 조건과 표시 수를 적용합니다.** ‘저녁 강좌 있는 곳만’을 선택하면 오후 6시 이후 시작 수업이 있는 시설만 표시합니다. 주말 저녁도 포함합니다.

저녁·주말 강좌 수는 해당 수업이 하나 이상 있는 **강좌 수**입니다. 한 강좌가 월·수·금 저녁에 운영되더라도 저녁 강좌는 1개로 셉니다.

## 정렬과 표시 범위

시설은 집계기간의 수강 신청 누계가 많은 순서로 불러옵니다. 기본 표시 한도는 60곳이며 API에서 최대 200곳까지 요청할 수 있습니다.

서버는 표시 한도의 두 배까지 먼저 불러온 뒤 저녁 조건을 적용합니다. 따라서 결과가 한도보다 적어도 지역 내 해당 시설을 모두 살펴본 결과라고 단정하지 않습니다.

종목 필터는 **시설의 종목 목록**에 적용합니다. 카드의 강좌 수와 최저 수강료는 그 시설의 집계기간 내 전체 종목 강좌를 기준으로 계산하므로, 선택한 종목의 개수·요금만을 뜻하지 않습니다.

## 시설을 선택하면

시설 ID로 같은 사용 버전의 시설을 조회하고 주소·상세 주소·전화·교통 정보와 강좌 목록을 돌려줍니다. 강좌는 마지막 기록월이 최근인 순서로 최대 50개입니다.

상세 목록은 집계기간으로 다시 제한하지 않습니다. 목록 필터를 해제하고 과거 기록이 있는 시설을 선택하면 오래된 강좌도 확인할 수 있습니다.

| 상세 결과 | 뜻 |
|---|---|
| 강좌·종목 | 공개 이용현황에 기록된 강좌 이름과 운동 종목 |
| 시간 | 별도 시간표 자료에서 연결한 요일·시각. 미확인은 상시 이용 가능이 아님 |
| 월 수강료 | 월별 이용현황에서 마지막으로 확인된 금액을 월 수강료로 해석한 값 |
| 마지막 집계월 신청 | 해당 강좌의 마지막 기록월과 그 월의 신청 인원 |

## 결과를 해석할 때

- **현재 모집·잔여석 조회가 아닙니다.** 공개 자료에 기록이 있어도 현재 영업·개설·가맹 유지 여부는 시설에 확인해야 합니다.
- **0과 미확인을 구분합니다.** 확인된 0원과 가격 자료 없음은 다릅니다. 가격 `–`는 무료가 아니라 미확인입니다. 최저 수강료는 확인된 값만 비교하며 카드에서 자료가 없으면 표시하지 않습니다.
- **신청 인원은 실제 이용 희망 건수와 다릅니다.** 정렬에 쓰는 누계는 월별·강좌별 신청 연인원이므로 같은 사람이 반복 포함될 수 있습니다. 서비스의 ‘시설 이용 희망 등록’ 수와 별개입니다.
- **도보시간은 전체 이동시간이 아닙니다.** 연결된 정류장 중 최소 도보시간을 분 단위로 반올림하며, 이용자 출발지에서의 경로를 계산하지 않습니다.
