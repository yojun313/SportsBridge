# 개발자 제안 게시판

이용자와 관리자가 서비스 개선 의견을 개발자에게 전달하는 게시판입니다. 외부 데이터셋이나 AI를 사용하지 않고, 직접 작성한 글을 MongoDB에 저장합니다.

## 두 게시판의 차이

| 구분 | 이용자 제안 게시판 | 관리자 제안 게시판 |
|---|---|---|
| 화면 | `/user/suggestions` | `/admin/suggestions` |
| 작성·열람 | 누구나 | 로그인한 최고 관리자·승인된 관리자 |
| 작성자 표시 | 익명 | 입력한 작성자 이름 + 로그인 계정 아이디 |
| 작성자 저장 | 계정·이름·IP를 게시글에 저장하지 않음 | 이름과 서버가 확인한 계정 아이디 저장 |

관리자 게시판은 `ADMIN_AUTH_ENABLED=false`일 때도 로그인이 필요합니다. 승인 대기·반려·권한 해제 계정에는 유효한 관리자 신원이 부여되지 않아 이용할 수 없습니다. 이름은 작성자가 입력하며, 계정 아이디를 함께 표시해 계정을 확인할 수 있습니다.

## 처리 흐름

1. 제목 2~100자, 내용 5~5,000자를 입력합니다. 관리자 이름은 1~40자입니다. 양끝 공백은 제거하고 알 수 없는 입력 필드는 거절합니다.
2. 서버가 게시판 종류와 관리자 신원을 확인합니다. 이용자 글에 이름이나 계정 필드를 넣는 요청은 거절합니다.
3. 과도한 등록을 제한합니다. 이용자 요청은 접속 IP, 관리자 요청은 계정 기준으로 1시간에 5건까지 허용합니다. IP는 게시글에 저장하지 않고 프로세스 메모리의 요청 제한에만 사용합니다.
4. `suggestions` 컬렉션에 `board`, `title`, `content`, `createdAt`을 저장합니다. 관리자 글에는 `authorName`, `authorUsername`을 추가합니다.
5. 목록 조회는 `board`로 분리하고 최신순으로 20건씩 반환합니다. 관리자 계정 정보가 공개 게시판 응답에 섞이지 않도록 반환 필드도 명시합니다.
6. 화면에는 글을 HTML이 아닌 텍스트로 삽입합니다. 입력한 줄바꿈은 유지합니다.

## 관리와 해석

- 이용자 게시판은 공개되므로 본문에 개인정보를 작성하지 않도록 안내합니다.
- 최고 관리자만 각 게시판에서 글을 삭제할 수 있습니다. 일반 관리자·익명 이용자는 삭제할 수 없습니다.
- 글 등록은 강좌 신청·시설 이용 희망 등록과 별개이며 통계·가맹 검토 점수에 반영하지 않습니다.
- 등록 시 이메일을 발송하지 않습니다. 개발자는 게시판을 열어 의견을 확인합니다.
- 별도 수정·답글·첨부파일·처리 상태 기능은 제공하지 않습니다.
- 저장 컬렉션은 CSV 재반영 대상에 포함하지 않으므로 공개 데이터 재반영으로 글이 교체되지 않습니다.
