# 화면 안내와 공통 UI

기준: 2026-10-30 현재 코드. 첫 화면·메뉴·지역 선택·서비스 안내·툴팁을 공통 방식으로 제공하는 기능입니다. 이 계층에서 원본 CSV를 직접 파싱하거나 새로운 추천 점수를 계산하지는 않습니다.

## 화면에 필요한 정보는 어디서 가져오나요?

서버는 페이지를 만들 때 사용 중인 데이터 버전, 자료 반영 기록, 최신 강좌월, 집계 시작월, 시도·시군구 목록과 AI 기능 설정을 조회해 템플릿에 전달합니다. 같은 메타데이터는 `GET /api/metadata`로도 받을 수 있습니다.

지역 목록은 `region_stats`, 사용 버전은 `catalog_state`, 파일·처리 건수는 `datasets`, 기준월은 `gap_aggregates`에서 가져옵니다. 첫 화면의 시설·강좌 수는 해당 버전의 반영 작업 기록에 저장된 건수이며 현재 모집 인원을 새로 센 값이 아닙니다.

공통 화면 틀은 머리말·본문·화면 도움말·꼬리말·모바일 메뉴를 조립합니다. 페이지별 기능은 같은 틀 안에서 자신의 입력·조회 결과를 표시합니다.

## 메뉴와 지역 선택

- 첫 화면 `/`은 이용자용·담당자용 이동 경로와 데이터 현황을 보여줍니다. 이용자용에는 검색·시설·공간·희망 등록·지원금 계산, 담당자용에는 현황·가맹 검토·지원 방안·데이터 관리 등을 표시합니다.
- 메뉴는 현재 페이지의 이용자용·담당자용 구분과 주소로 선택합니다. 메뉴가 보인다는 것 자체가 관리자 권한을 받은 상태를 뜻하지는 않습니다.
- 모바일은 주요 메뉴 네 개와 ‘더보기’를 사용합니다. 더보기에는 나머지 기능과 모드 전환이 있고, 닫기·바깥 영역·뒤로 가기·Escape로 닫습니다.
- 공통 지역 선택기는 **URL의 `region` → 이 브라우저에 저장된 `sb_region`** 순서로 초기 지역을 정합니다. 둘 다 없으면 이용자가 시도·시군구를 선택합니다.
- 시군구를 바꾸면 브라우저에 지역코드를 저장하고 지역 변경 이벤트를 보냅니다. 각 화면이 이 이벤트를 받아 자신의 자료를 다시 조회합니다. 현재 위치를 자동으로 측정하지는 않습니다.

예를 들어 브라우저에 종로구가 저장돼 있어도 강남구 코드가 포함된 URL로 들어오면 그 화면은 강남구를 먼저 선택합니다. 이 공통 선택기는 지역 현황·시설 검색·공공 운동 공간 등에 쓰이며 모든 화면의 독립 입력폼을 강제로 같은 값으로 바꾸지는 않습니다.

## 서비스 안내는 어떻게 구성하나요?

`/guide`와 `/user/guide`는 같은 안내 템플릿에서 서비스 개요, 이용자 기능, 담당자 기능, 자료·계산 기준을 나눠 보여줍니다. 목차와 본문 제목은 같은 항목 이름 목록을 사용하고 각 화면으로 이동하는 링크를 제공합니다.

데이터셋 표는 출처 등록소의 10종 목록을 템플릿 공통값으로 받아 만듭니다. 기능별 설명·계산 기준·용어표·FAQ는 코드에 작성한 안내 문장입니다. `/user/help`는 이용자 기능의 짧은 사용 순서와 결과 읽는 방법을 제공합니다.

안내 문장은 AI가 화면을 읽고 자동 생성하는 것이 아닙니다. 기능이나 데이터 처리 방식이 바뀌면 해당 설명도 코드와 함께 관리해야 합니다.

## 툴팁과 도움말 표시 로직

| 사용자 동작·상태 | 공통 처리 |
|---|---|
| 항목 위에 마우스를 올림 | `data-tooltip`, 기존 지역 설명용 `data-gap-tip`, `data-help`에서 설명을 찾아 **0.7초 뒤** 표시 |
| 다른 곳으로 이동·클릭·스크롤 | 대기 중인 표시를 취소하고 열린 툴팁을 닫음. 화면 크기 변경·창 이탈·Escape 등도 닫기 처리 |
| 키보드로 항목에 초점 이동 | 키보드 조작 상태에서는 기다리지 않고 설명 표시. 기존 접근성 설명 연결도 유지 |
| 검색·계산으로 새 항목이 생김 | 화면 요소의 추가와 설명 속성 변경을 감지해 같은 툴팁 기능을 붙임 |
| 기본 `title` 설명이 있음 | 공통 설명으로 옮기고 기본 `title`을 제거해 두 종류가 겹쳐 뜨지 않게 처리 |
| `?` 도움말 선택 | 해당 기능의 제목과 자세한 설명을 공통 팝업에 표시 |
| 아래쪽 ‘이 화면의 기능·용어 안내’ 선택 | 현재 보이는 본문·상단 메뉴의 설명을 모으고 같은 설명은 한 번만 표시 |

긴 `data-help` 설명은 마우스 툴팁에서는 자세한 안내를 열라는 짧은 문구로 바꾸고, `?`를 선택했을 때 전체 내용을 보여줍니다. 모바일에서는 마우스를 올릴 수 없어도 `?`와 화면 설명 모음을 사용할 수 있습니다.

설명은 화면 안의 텍스트로 표시하며 HTML로 실행하지 않습니다. 항목에 설명이 작성돼 있어야 표시할 수 있으므로, 공통 기능이 모든 단어의 의미를 스스로 추론하는 것은 아닙니다.

## 공통 표시와 저장의 범위

숫자·원화·비율·요일·시각은 공통 함수로 표기합니다. 미확인 숫자는 `–`, 시간표가 없으면 ‘시간 미확인’으로 표시합니다. 출처 배지는 공공자료·규칙·AI 추출·담당자 확인·가정 등을 구분합니다.

모바일 입력 중에는 보이는 화면 높이를 반영해 키보드가 입력창을 가리지 않도록 조정합니다. 공통 상단 진행 바는 서버의 데이터 반영 상태를 주기적으로 조회해 작업 중임을 알립니다.

화면에 보이는 값과 저장 위치는 구분해야 합니다. 지역·관심 강좌·지원금 입력·시나리오 등 브라우저 보관 내용은 다른 기기로 자동 전달되지 않습니다. 반면 조회·검증·계산 요청은 서버에서 처리할 수 있습니다. 자세한 내용은 [지원금 계산과 관심 저장](07_지원금_계산과_관심_저장.md), [지원 방안 입력](10_지원_방안_입력.md)을 참고하면 됩니다.
