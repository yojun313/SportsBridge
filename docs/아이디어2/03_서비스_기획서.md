# 운동권 복구소 — 서비스 기획서

작성일: 2026-09-18 · 버전 0.1

## 1. 한 문장 정의

**지자체가 스포츠강좌이용권을 쓸 수 없는 운동 수요에 대해, 시설 가맹·수업 신설·이동 지원을 어떤 조합으로 시행해야 하는지 계산하고 현장 협의까지 준비하는 웹 서비스.**

입력은 지역의 공급 자료와 익명 수요 조건, 담당자가 검토하는 개선 조치입니다. 출력은 **예산별 개선 조합, 계산상 연결 가능한 수요, 남는 공백, 성립에 필요한 확인사항**입니다.

이름의 ‘운동권’은 서비스의 지향점을 표현하며 법적 권리 충족을 판정한다는 의미가 아닙니다.

## 2. 아이디어1과 바뀌는 점

| 항목 | 아이디어1 | 아이디어2 |
|---|---|---|
| 사용자 | 보호자 | 지자체·체육회·복지기관 실무자 |
| 상황 | 기존 수업 중 적합한 것을 찾음 | 적합한 공급이 없어 무엇을 바꿀지 결정 |
| 분석 단위 | 개인과 강좌 | 익명 수요 집단·강좌 공급·개선 조치의 관계 |
| 핵심 결과 | 추천 목록·시간표 | 상호의존적인 개선 묶음과 근거를 담은 실행안 |
| 성공 기준 | 탐색 시간 감소 | 계획 작성 시간, 실제 가능한 대안의 발견, 후속 개설·참여 |

## 3. 문제와 근거

2024년 이용권 지원기간 미소진 사유 중 시설 부족이 35.0%였다는 국회예산정책처의 분석을 출발점으로 삼습니다. 해당 응답 집단의 수치이며 전체 국민·이용자 비율이 아닙니다. [근거와 경쟁 비교](02_기존서비스조사_차별성.md)에 출처·해석 한계를 정리했습니다.

가설: 담당자는 시설 수를 늘리는 것만으로 해결되지 않는 ‘가맹은 되지만 수업시간이 안 맞음’, ‘시간은 맞지만 이동이 안 됨’, ‘조건은 맞지만 좌석이 부족함’ 등의 결합 문제를 반복적으로 조정해야 합니다.

인터뷰에서 이 업무가 실제로 존재하지 않거나 기존 도구로 쉽게 해결된다면 기획의 필요성이 낮아집니다. 현재 구매 의향이나 운영기관 협력을 확보한 상태는 아닙니다.

## 4. 대표 사용자

- 주 사용자: 한 시군구의 스포츠복지 담당자. 제한된 추가 사업비로 어느 기관·시설과 협의할지 결정.
- 협력 사용자: 지역아동센터 등 복지기관. 아동을 식별하지 않는 집단별 희망 종목·가용시간·인원 제공.
- 공급 확인자: 체육시설 운영자. 가능한 수업·정원·가맹 의향·비용을 확인.

시제품에서는 한 담당자가 조건을 입력합니다. 여러 기관의 자동 메시지·계정·업무승인 시스템은 제외합니다.

## 5. 핵심 사용 흐름

1. 지역과 종목을 선택한다. 실제 데이터의 시설·가맹·강좌·기준일을 확인한다.
2. 익명 수요 집단을 입력한다. 예: 센터 A의 수영 희망 8명, 화·목 16~18시, 주 2회.
3. 알려진 공급 조건과 불명 조건을 확인한다. 공개 목록에 잔여정원이 없으면 담당자가 입력하거나 불명으로 남긴다.
4. 현재 조건으로 연결 가능한 수요와 실패 이유를 본다.
5. 개선 조치를 만든다. 예: B시설 가맹 협의, 화·목 수업 신설, 기관 이동 지원.
6. 예산과 목표를 정해 조합을 계산한다. 조건별 가정·비용·충돌을 비교한다.
7. 선택한 조합에서 어떤 조건이 아직 미확인인지 확인하고 협의용 계획서를 출력한다.
8. 담당자가 확인 내용을 입력하면 다시 계산한다. 시스템이 실제 가맹·개설·예약을 실행하지 않는다.

## 6. 대회 시연용 예시 — 전부 가상 숫자

실제 공공시설 위치를 쓸 수 있더라도 아래의 수요·비용·좌석·의향은 합성 예시임을 화면과 보고서에 표시합니다.

| 항목 | 가정 |
|---|---|
| 수요 | 동일한 조건의 가상 수요 10명 |
| 기존 공급 | 조건에 맞는 가상 추가 좌석 2석 |
| 조치 A | B시설 가맹 준비. 가정 비용 20만 원 |
| 조치 B | B시설에 해당 시간대 강좌 8석 개설. 가정 비용 60만 원 |
| 논리 관계 | 새 8석은 가맹과 개설 두 조건이 모두 충족되어야 이용권 공급으로 인정 |

결과: 현재 2명분, A만 또는 B만 시행해도 2명분, A+B이면 10명분의 **모델상 배정 가능량**. 80만 원 미만의 예산에서는 이 조합을 선택할 수 없습니다. 실제 참여자·절약한 지원금·확정 사업비가 아닙니다.

시연의 중심 장면은 A와 B를 각각 선택했을 때와 함께 선택했을 때 결과가 달라지는 것입니다. 정렬된 추천 카드만 보여주면 이 아이디어의 핵심이 구현된 것이 아닙니다.

## 7. 데이터의 역할과 한계

| 계층 | 데이터 | 역할 |
|---|---|---|
| 공공 공급 | 시설·강좌·전체 시설 | 실제 검토 가능한 장소와 공개 수업의 초기 목록 |
| 공공 이용 이력 | 강좌별 월 신청인원·기간·가격 | 이용 기록의 규모와 지속성 참고. 잠재 수요 추정값으로 전용하지 않음 |
| 공공 지역 맥락 | 대상자·수급자·시설 수 | 지역 비교·사업 배경 |
| 공공 접근 맥락 | 가맹시설 인접 대중교통 | 마지막 도보 구간 참고. 전체 통학 경로·시간을 뜻하지 않음 |
| 현장 수요 | 기관별 익명 희망 조건·인원 | 모델의 실제 수요. 공공 자료에 없음 |
| 현장 공급 | 잔여정원·공간·강사·가맹 가능 여부 | 실행 가능한 배정·조치 판단 |
| 계획 가정 | 비용·개설 시점·이동 지원 | 비교할 시나리오. 사실과 분리 |

원본에 없는 잠재 수요·주소·장애 유형·수급 유형을 체력측정 자료나 시설 위치에서 추정해 채워 넣지 않습니다.

## 8. 두 가지 분석 모드

### 구조 탐색 모드

공공 데이터만 있을 때 사용합니다. 종목·요일·시간·가맹 여부를 비교하고 정보 누락과 추가 협의 후보를 보여줍니다. 정원을 모르므로 ‘추가 참여 가능 인원’, ‘수용 완료’, ‘최적 사업비’는 출력하지 않습니다.

### 정원·비용 입력 시뮬레이션 모드

수요·좌석·조치 비용·운영 조건이 입력되었을 때 계산합니다. 각 입력은 `공공자료`, `담당자 확인`, `가정`으로 구분합니다. 가정이 있으면 결과에 가정 의존성을 표시합니다.

‘확인된 조건만 사용’과 ‘명시한 가정을 포함’을 별도로 계산할 수 있습니다. 두 결과는 통계적 신뢰구간이 아닙니다. 모르는 정보를 숨기기 위한 범위 숫자를 만들지 않습니다.

## 9. 계산할 제약

- 종목, 대상 연령·강습 수준, 이용권 사용 조건.
- 필요한 모든 수업일과 가용시간 일치.
- 추가 좌석의 상한. 과거 신청인원을 빈자리로 해석하지 않음.
- 기관이 확인하거나 가정으로 입력한 이동 가능 여부·시간.
- 신규 수업의 공간·강사·시간 충돌.
- 조치 간 선행 조건, 함께 필요한 조건, 동시에 시행할 수 없는 관계.
- 계획 기간 내 개설 가능 여부, 비용 합계와 예산.

건물 내부 무장애 접근성이 확인되지 않은 경우 장애인 수요에 적합하다고 판정하지 않습니다. 시제품은 일반 유·청소년 한 종목으로 제한하고 장애인 확장은 별도 현장 검증 후 진행합니다.

| 화면 | 핵심 기능 |

| 지역 공급 탐색 | 가맹·강좌·후보시설·자료 기준일, 필터 가능한 목록 |

지도는 보조 기능입니다. 핵심 관계는 수요 집단→공급 후보→필요 조치의 작은 관계도와 비교표로 보여줍니다. 애니메이션을 위해 데이터가 있는 척하지 않습니다.

## 11. 무엇을 최적화하는가

첫 번째 목표: 입력된 조건과 예산 안에서 배정할 수 있는 수요 단위의 합 최대화.

같은 배정량이면: 비용 최소화 → 조치 수 최소화 → 안정적인 ID 순서. 정책적 우선순위나 집단별 최소 보장은 담당자가 명시해야 하며 모델이 임의로 취약성 점수를 만들지 않습니다.

정원이 없는 모드에서는 조합별로 새로 연결되는 **수요 유형 수**만 표시할 수 있습니다. 이것을 사람 수로 변환하지 않습니다.

## 12. 시제품 범위

- 한 시군구, 한 종목, 수요 집단 3~10개.
- 공급 옵션 최대 30개, 개선 조치 최대 10개.
- 실제 공개 데이터의 시설·강좌 목록과 검증된 조인.
- 수동 입력한 현장 조건 또는 명확히 표시한 가상 조건.
- 현재/개선 후 비교, 결합 조치 계산, 근거 추적, 로컬 시나리오 저장, 인쇄.
- 기존 시설 하나를 제외하는 스트레스테스트는 핵심 완료 후 추가.

제외: 전국 수요 자동 추정, 자동 가맹 신청, 정책 자격 확정, 예산 집행, 실시간 잔여석, 실제 통학차량 배차, 건강 효과 예측, 주민 개인 계정, 메시지 자동 발송.

## 13. ‘대체하기 어려움’을 검증할 방법

같은 작은 문제를 다음 방법으로 풀어 비교합니다.

1. 담당자 또는 연구자가 기존 목록과 엑셀로 계획 작성.
2. 각 조치의 단독 효과/비용 순으로 선택하는 단순 방식.
3. 운동권 복구소의 결합 조치 계산.

비교 항목: 작성 시간, 조건 위반, 정원 초과, 동일 예산에서의 모델 배정량, 조합 누락, 근거 추적 가능성. 결합 효과가 없는 쉬운 문제도 포함해 유리한 예시만 고르지 않습니다.

사용자 인터뷰 목표는 담당자 2명 이상이며 아직 수행하지 않았습니다. 실제 운영 검증 없이 ‘참여율 증가’, ‘예산 절감’, ‘지자체 도입’이라는 성과를 발표하지 않습니다.

## 14. 실현 가능성 판단 기준

- 필수 CSV의 공통 ID 또는 정확한 시설명·주소 연결이 충분한가?
- 공개 강좌의 종목·시간·기간을 해석할 수 있는가?
- 실제 수요 조건과 공급 확인을 제공할 협력자가 있는가?
- 입력 준비에 드는 시간이 수작업 계획보다 과도하지 않은가?
- 새로 연결되는 수요가 있는 현실적 조치 후보를 만들 수 있는가?

첫 두 조건이 안 되면 자동 탐색 범위를 축소합니다. 현장 협력자가 없으면 **공개 데이터 기반 정책 시뮬레이터**까지 만들 수 있지만, 현실에서 효과가 검증된 운영 서비스라고 부르지 않습니다.
