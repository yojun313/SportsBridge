# 아이디어2 — 운동권 복구소

작성일: 2026-09-18 · 상태: 조사 및 설계 완료, 실제 CSV 검증·개발 전

> **“이용권이 있어도 갈 수 있는 수업이 없다면, 지역에서 무엇을 함께 바꿔야 운동 기회가 생기는가?”**

지자체·체육회·복지기관을 위한 **스포츠복지 공급 개선 설계 서비스**입니다. 지역의 수업, 이용권 가맹 여부, 이동 조건과 수요를 연결하고, ‘신규 가맹 + 수업 신설’처럼 함께 시행해야 효과가 생기는 조합을 계산합니다. 예산 안의 실행 후보, 남는 공백, 현장 확인사항을 하나의 계획으로 제공합니다.

아이디어1의 개인 강좌 추천에서 **서비스 사용자, 해결 문제, 결과물**을 모두 바꿨습니다. 기존 시설이 중단되는 상황은 추가 시나리오이며, 핵심은 현재 운동 기회가 없는 집단의 공급 조건을 개선하는 것입니다.

## 정직하게 말할 수 있는 독창성

공단의 공개 상품 **95종 전체를 16개 페이지에서 수집하고 설명을 검토**했습니다. 해외의 체육시설 수요·공급 모델, 스포츠 바우처 관리 서비스, 시설 일정 관리 소프트웨어까지 비교했습니다.

**‘한국 스포츠강좌이용권의 가맹·강좌·접근 제약을 연결해, 상호의존적인 개선 조합과 근거·미확인 조건까지 산출하는 동일한 서비스’는 이번 공개 조사에서 확인하지 못했습니다.** 하지만 인접 솔루션과 엑셀·GIS·담당자 협의라는 대체 수단은 존재합니다. 전 세계 최초·경쟁 없음·절대 대체 불가능을 보증하지 않습니다. 단순 추천보다 독립적인 문제를 해결하는 신규 서비스 후보라는 판단입니다.
