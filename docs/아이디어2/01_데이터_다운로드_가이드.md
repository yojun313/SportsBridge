## 다운로드 후 중요한 확인

### 1번: 이용현황

- 한 행이 시설×강좌×월인지, 어떤 중복이 있는지.
- 신청인원은 중복 가능한 등록 건수인지, 취소 반영 여부는 무엇인지.
- 이용권 사용자만 포함하는지, 실제 출석·결제와 어떤 차이가 있는지.
- 최신 월과 시계열 제공 범위.
- 시설·강좌 ID 유무, 2·3번과 연결 가능 여부.

**신청인원은 잠재 수요·잔여석·고유 주민 수·출석자 수가 아닙니다.** 수강료×신청인원을 정부 지원금 집행액으로 계산하지 않습니다. 여러 달 합산을 ‘사람 수’라고 부르지 않습니다.

### 2·3번: 시설과 강좌

- 공통 식별자, 주소·시설명 정규화, 폐업·운영 상태 유무.
- 요일 비트문자열의 선행 0 보존, 시간 파싱, 가격 단위.
- 모든 요일이 필수 출석인지 선택 가능일인지, 대상 연령과 강습 수준.
- 정원·잔여정원·지도자 여유는 없을 수 있으며 임의로 생성하지 않음.

### 4번: 전국시설

가맹 목록에서 찾지 못했다고 바로 ‘미가맹’으로 단정하면 안 됩니다. 이름·주소 차이, 누락, 기준일 차이 때문일 수 있습니다. 처음에는 **가맹 여부 추가 확인 후보**로만 분류합니다. 종목·교육 공간·강사·등록 자격·신규 모집 가능 여부를 별도 확인합니다.

### 5번: 대중교통

이 데이터는 **이용권 가맹시설 대상 750m 범위**입니다. 기존에 본 ‘체육시설 인접 대중교통 정보’는 공공체육시설 대상 1km 범위의 다른 상품입니다. 둘을 혼동하지 않습니다. 집→정류장, 운행노선·배차·환승, 휠체어 접근성을 알 수 있는 데이터가 아닙니다.

## 공개 데이터 외에 반드시 구분해야 할 입력

| 필요한 입력 | 얻는 방법 | 없을 때 |
