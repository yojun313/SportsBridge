# 전체 데이터 95종 검토와 아이디어 선택 근거

조사 기준: 2026-09-18 · 범위: 사용자가 지정한 문화 빅데이터 플랫폼 국민체육진흥공단 기관 페이지

## 1. ‘모두 참고’의 범위

[기관 페이지](https://www.bigdata-culture.kr/bigdata/user/data_market/agency/detail.do?id=kspo_org)의 전체 상품 목록 16페이지에서 **중복 없는 상품 ID 95개**와 제목·공개 설명을 수집해 검토했다. 원문과 직접 링크는 [전체 목록](00_전체데이터_95종_목록.md)에 보존했다.

이 범위는 해당 기관에 공개 나열된 모든 상품이다. 국내 모든 체육 공공데이터, 각 상품의 모든 역사적 파일, 로그인 후 다운로드 가능 여부까지 전수 검증했다는 뜻은 아니다. 실제 CSV·JSON 본문과 컬럼 정의서를 다운로드한 상태도 아니다. 따라서 ‘사용 가능한 데이터’는 우선 **공개 목록에 존재하는 데이터 후보**를 의미한다.

재현 자료:

- [수집 스크립트](research/collect_catalog.py): 기관 페이지가 사용하는 공개 목록 요청을 페이지별로 조회.
- [메타데이터 스냅샷](research/kspo_catalog_2026-09-18.json): ID·제목·설명·목록 페이지·상세 링크.
- 상품 상세 링크와 설명은 당시 스냅샷이다. 실제 이용·개발 전 기준일·형식·라이선스를 재확인한다.

## 3. 아이디어를 바꾼 핵심 발견

### 강좌별 이용 이력이 있다는 점 — 5번

단순 시설 위치뿐 아니라 강좌·월·신청인원·기간·가격을 포함한 상품이 있다. 공급 목록에 실제 이용 기록이라는 맥락을 더할 수 있다. 다만 한 사람이 여러 달 등장할 수 있고 이용하지 못한 사람은 보이지 않는다. 이력으로 잠재 수요를 자동 복원하는 것은 근거가 없다.

### 가맹시설과 전체 시설 목록을 비교할 수 있다는 점 — 80번과 64번

기존 가맹시설에서만 추천하는 대신 추가 협의할 시설 후보를 찾을 수 있다. 두 목록을 연결하지 못한 것은 곧 비가맹이나 유휴 시설이라는 뜻이 아니다. 정확한 결합과 운영자 확인이 필요하다.

### 시간·가격이 있는 강좌 목록 — 74번

시설 수가 충분해도 필요한 시간·종목·연령대의 수업이 없을 수 있다. 주소와 거리만 보는 추천을 넘어 ‘어느 수업 조건을 바꿔야 하는가’를 검토할 수 있다. 원본의 회차 규칙·대상 조건이 부족하면 보완 입력이 필요하다.

### 이용권 전용 접근 정보 — 6번

이용권 및 장애인 이용권 가맹시설의 반경 750m 정류장·지하철 출구와 도보 구간 정보가 있다. 공공체육시설 중심의 8번, 반경 1km 데이터와 구분된다. 접근성의 일부 근거이지 전체 통학·안전·무장애 경로는 아니다.

### 지역 단위 이용권 맥락 — 26번

대상 인원·수급 인원·시설 수로 지역 맥락을 읽을 수 있다. 설명에 제시된 기준과 실제 파일 기준을 확인하고, 분모·기간이 맞지 않는 비율을 계산하지 않는다. 대상자와 수급자의 차이를 곧바로 ‘운동하고 싶은데 못 하는 사람’으로 정의하면 안 된다.

## 4. 검토했으나 중심 아이디어로 선택하지 않은 방향

| 후보 | 데이터 근거 | 선택하지 않은 이유 |
|---|---|---|
| 개인 맞춤 종목·시설 추천 | 체력·처방·강좌·시설 | 기존 매칭·추천과 겹치며 개인 건강 상태·유효한 추천 근거가 더 필요 |
| 지역 시설 수요·공급 지도 | 시설·지역 이용·좌표 | 해외 Facilities Planning Model 등 인접 도구가 있음. 지도만으로 차별성이 약함 |
| 시설 폐쇄 후 대체 장소 안내 | 강좌·시설·공지 | 일정관리·대체시설 검색과 겹침. 전국 실시간 폐쇄 정보도 확보되지 않음 |
| 안전등급 기반 위험·폐쇄 예측 | 33·34번 | 사고 라벨·현재 운영 상태 없이 위험 확률이나 폐쇄 필요성을 만들 수 없음 |
| 장애인 접근 가능 운동 추천 | 4·27~31번 등 | 사회적 필요는 높지만 장애별 접근·장비·지원 인력 확인이 필수. 초기 범위를 벗어남 |
| 지도자 빈 시간 자동 매칭 | 49·72·87·88·91번 | 시험·자격·연수 정보이지 현재 근무 가능 시간·연락 동의를 가진 인력 명부가 아님 |
| 경륜·경정 성적 분석 | 33개 관련 상품 | 양은 많지만 사용자가 찾는 생활체육 사회문제와 방향이 다름 |

이는 ‘이 후보들로 아무 서비스도 만들 수 없다’는 뜻이 아니다. 이번 대회에서 공개 데이터의 역할을 설명하면서 차별성과 구현 범위를 함께 확보하려는 선택이다.

## 5. 최종 선택 — 단순 대안 추천이 아닌 상호의존 개선 조합

공개 데이터는 현재 공급·이용 이력·추가 후보·접근 맥락을 제공한다. 그 위에 실제 수요와 운영 조건을 명시적으로 입력하면 **가맹만으로도, 수업 신설만으로도 해결되지 않는 공백을 두 조치의 결합으로 해결하는 계획**을 만들 수 있다.

최적화 수학 자체가 새로운 것은 아니다. 기존 데이터 상품을 특정 행정 의사결정 과정에 연결하고, 가정과 현장 검증을 추적하는 제품 구성에 차별성을 둔다. 기존 상품과의 비교 및 발견하지 못한 범위는 [경쟁 조사](02_기존서비스조사_차별성.md)를 따른다.

## 6. 반드시 남겨야 할 데이터 공백

이번 95종의 공개 설명만으로 다음을 확보했다고 할 수 없다.

1. 현재 운동 기회가 없는 주민의 구체적 희망·가용시간·인원.
2. 강좌별 실제 추가 수용 인원과 현재 모집 상태.
3. 시설의 신규 가맹·개설 의향과 인력·공간 여유.
4. 개설·가맹 준비·이동 지원의 실제 비용과 준비기간.
5. 수요 집단 출발지부터 수업 종료 후 복귀까지의 실제 이동 가능성.

따라서 현장 입력 없이 완전한 정책 실행안을 자동 작성한다고 주장하지 않는다. 공공 데이터만 있으면 구조 탐색, 추가 조건이 있으면 시뮬레이션, 실제 협의가 끝나야 실행 검토로 단계가 나뉜다.

## 7. 개발 착수 판단

필수 원본의 ID·시간·종목·주소 연결이 확인되고 작은 합성 예시에서 조합 계산이 정확하면 시제품 개발은 가능하다. 데이터 확보 전에 전국 실시간 서비스나 실제 참여 증가 수치를 약속하지 않는다.

**가장 큰 사업 위험은 알고리즘 구현이 아니라 현장 수요·수용 여력·비용을 지속적으로 확보하는 일이다.** 한 기관의 반복 계획 업무에 실제로 도움이 되는지 확인하는 것이 다음 검증 단계다. 이 검증이 안 되면 ‘대체 불가능한 서비스’가 아니라 ‘설득력 있는 시뮬레이션 데모’에 머문다.
