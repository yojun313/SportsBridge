# 공공 운동 공간

기준: 2026-10-30 현재 코드. 같은 시군구의 **개방학교 체육시설**과 **공공체육시설**을 따로 조회하는 기능입니다. 학교 목록에는 희망 시간과 겹치는 구간을 계산하고, 일반 공공시설에는 시설·안전·교통 정보를 표시합니다.

## 입력과 사용 데이터

화면은 `/user/spaces`, 조회 API는 `GET /api/user/spaces`입니다. 시군구, 선택 요일, 시작·종료 시각을 입력합니다. 시각은 브라우저에서 하루 시작부터 몇 분인지를 나타내는 숫자로 바꿔 보냅니다.

| 데이터 | 쓰는 항목 | 결과에서의 역할 |
|---|---|---|
| 개방학교 체육시설 | 학교명·주소·종목·개방시간·개방기간·편의시설·기준연도 | 학교 목록과 시간 교집합 |
| 전국체육시설현황·전국공공체육시설 | 지역·공공 구분·운영상태·업종·시설유형·전화 | 일반 공공시설 목록 |
| 체육시설 안전점검정보 | 등급·점검일 | 일반 공공시설의 점검 정보 |
| 체육시설 인접 대중교통 | 정류장·도보시간 | 일반 공공시설의 접근 정보 |
| 스포츠 강좌이용권 시설·이용현황 | 시설 목록 연결 결과 | 일반 공공시설의 ‘가맹 목록 연결됨’ 표시 |

이 원본들은 공통 가공 과정에서 `facilities_all`에 모입니다. 안전·교통은 같은 지역·정리한 시설명·주소 기준으로 연결하고, 가맹 목록과의 연결 결과는 별도 표시로 보관합니다. [공통 가공 문서](01_데이터셋과_공통_가공.md)를 참고하면 됩니다.

## 학교 개방시간을 비교하는 방법

1. 사용 중인 데이터 버전에서 선택한 시군구의 `open_schools` 출처가 있는 시설을 찾습니다.
2. 원본 개방시간 문장에서 `월요일: 18:00~21:00` 같은 패턴을 찾습니다. 월~일을 0~6으로, 시각을 분으로 바꿉니다. 강좌표의 7자리 요일 비트와는 다른 처리입니다.
3. 종료가 시작보다 늦은 구간만 사용합니다. `월~금`, `평일 저녁`처럼 이 패턴과 다른 표현을 자유롭게 이해하는 기능은 아닙니다.
4. 희망 시간과 학교 개방시간의 요일이 같고 **일부 시간이라도 겹치면** 포함합니다. 겹치는 시작은 두 시작 중 늦은 시각, 끝은 두 종료 중 빠른 시각입니다.
5. 화면에는 겹치는 구간이 있으면 그 구간을, 시간 필터가 없으면 해석된 개방시간을 표시합니다.

예를 들어 학교가 월요일 18~21시 개방이고 이용자가 월요일 20~22시를 입력하면, 결과에 포함되고 **20~21시**가 표시됩니다. 희망한 2시간 전체를 이용할 수 있다는 판정은 아닙니다. 21~22시는 맞닿기만 하므로 포함되지 않습니다.

요일을 ‘무관’으로 두면 시간 필터를 보내지 않습니다. API에서도 요일·시작·종료가 모두 있고 종료가 시작보다 늦을 때만 필터를 만듭니다. 그렇지 않으면 필터 없이 조회하므로, 종료 시각을 잘못 입력했다고 자동으로 결과가 0건이 되지는 않습니다.

시간 필터가 있으면 개방시간을 해석하지 못한 학교는 교집합이 없어 빠집니다. 필터가 없으면 그런 학교도 포함될 수 있고 ‘개방시간 미확인’으로 표시됩니다.

## 일반 공공체육시설을 찾는 방법

- 같은 시군구에서 공개 자료의 공공 구분이 `공공`, 운영상태가 `정상운영`이고 삭제 표시가 아닌 시설을 찾습니다.
- 이 목록에는 **위의 요일·시간 필터가 적용되지 않습니다.** 시설별 수업·개방 시간표를 비교하지 않고 기본 시설 정보를 조회하기 때문입니다.
- 이름·유형·주소·전화와, 연결된 정류장 도보시간·안전점검 등급을 표시합니다. 도보시간은 원본에서 가장 짧은 값을 분 단위로 반올림하며 새로운 이동 경로를 계산하지 않습니다.
- `voucherMatch`가 있으면 ‘가맹 목록 연결됨’을 표시합니다. 자료 사이에서 동일 시설로 연결됐다는 의미이며 현재 가맹 유지·지원 유형까지 확인한 결과는 아닙니다.

## 반환 결과와 표시 범위

API는 `schools`와 `public` 두 목록을 반환합니다. 학교는 종목·교집합 시간·편의시설·기준연도, 공공시설은 시설유형·연락처·안전·교통 정보를 중심으로 보여줍니다.

기본적으로 **목록별 최대 60곳**을 반환합니다. 같은 시군구를 기준으로 찾으며 거리순 정렬이나 현재 위치 기반 추천은 하지 않습니다. 강좌 찾기 화면에서도 같은 학교 시간 비교 함수를 사용하지만 기본 최대 표시 수는 20곳입니다.

## 결과를 해석할 때 주의할 점

- ‘공공’이나 ‘학교 개방’은 무료·예약 가능·지금 입장 가능을 보장하지 않습니다. 요금·신청 방법·실제 운영일은 시설에 확인해야 합니다.
- 학교 개방기간과 기준연도는 보관하지만, 현재 날짜가 개방기간 안인지 판정하는 조건으로 사용하지 않습니다. 학교 조회에는 일반 공공시설과 같은 운영상태 필터도 없습니다.
- 안전·교통 정보가 없는 것은 위험하거나 접근 불가하다는 뜻이 아닙니다. 학교 시간과 공공시설 운영상태 모두 공개 자료의 기록 기준입니다.
- 조회만 수행하며 시설 예약·수강 신청·스포츠 강좌이용권 결제를 실행하지 않습니다.
