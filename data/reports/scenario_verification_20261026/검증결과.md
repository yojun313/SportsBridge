# 지원 방안 시뮬레이션 검증

실제 서비스 https://sportsbridge.o-r.kr 에서 독립된 브라우저 세션으로 검증했습니다.
입력값은 사용법 확인을 위한 가정이며 실제 시설·수요·비용 자료가 아닙니다.

## 입력 조건

| 항목 | 가정값 |
|---|---|
| 수요 | 8명, 수영, 만 8~12세 |
| 가능 시간 | 월·수·금 16:00~18:00 |
| 수업 시간 | 월·수·금 16:00~17:00, 전 요일 필수 |
| 기존 강좌 추가 정원 | 0명 |
| 신설 강좌 기본 정원 | 0명 |
| 강좌 신설 조치의 정원 | 8명 |
| 가맹 협의 비용 | 200,000원 |
| 강좌 신설 비용 | 600,000원 |
| 선행 조건 | 강좌 신설에 가맹 협의 필요 |
| 예산 | 900,000원 |
| 이동 | 가능으로 가정 |

## 검증 결과

| 조건 | 실제 결과 |
|---|---|
| 정상 조건 | 현재 0명 → 가맹 협의+신설 8명, 총비용 800,000원 |
| 협의 계획서 | 선택 조합의 8명 결과 반영, 숫자·이름 검증 통과 |
| 예산을 700,000원으로 변경 | 800,000원 조합은 예산 초과, 최선 결과 0명 |
| 수요 가능 요일을 화·목으로 변경 | 월·수·금 강좌와 충돌, 두 조치 선택 시에도 0명 |
| 신설 조치 정원 미입력 | 검증 오류 표시 |
| 가맹 협의 비용 미입력 | 비용 미확인 조합을 최선 조합에서 제외 |

신설 조치만 선택하는 조합은 선행 조건을 충족하지 않아 비교 대상에서 제외되었습니다.
개별 효과 순 선택 방식은 효과가 없는 가맹 협의를 먼저 선택하지 않아 0명으로 나왔습니다.
기존 엔진 테스트 9개와 브라우저 검증 6개가 통과했습니다.

## 재현

지원 방안 화면의 `JSON 불러오기`에서 [scenario.json](scenario.json)을 선택하고
`검증` → `조합 계산`을 선택합니다. 현재 브라우저의 시나리오가 이 파일 내용으로 바뀝니다.
신설 강좌의 기본 정원은 0이고, 신설 조치가 8석을 추가하는 구성입니다.
